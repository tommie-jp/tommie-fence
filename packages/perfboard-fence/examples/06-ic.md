# IC と 3 ピンの部品

DIP と SIP は**アンカーを 1 つだけ書く**。ピンの位置はパッケージが決めていて、
書く人が選べないため — 8 個の穴を書かせるのは、選べないものを書かせること。

**配線は網ごとに色を分けてある** — 赤が +、黒が GND、残りを黄と白に振った。
同じ色の線は同じ網で、色が違えば別の網。交差する線は跨いで引くが、**跨ぎだけでは
「どの線がどこへ行くのか」までは追えない**ので、色で網をたどれるようにしてある
(実物でも被覆の色を分けて挿し、赤と黒は電源に取っておく)。

**基板の図の前に回路図を置く。** 実体配線図だけでは「なぜその穴なのか」が
読めないので、先に回路を見せてから基板に落とす。回路図は
[circuit-fence](../../circuit-fence/) の ` ```circuit ` フェンスで、
図は `npm run schematics --workspace=perfboard-fence` で作り直す
(描くのに TeX が要るので、基板の図とは別の工程になっている)。
**2 つの図のネットリストは同じ**になる — 違っていたら、どちらかが間違っている。

  - U1.1 -| 3,7

  - U1.8 -| 7,2
  - U1.7 -| 8,4

`dip8 e4` の `e4` は**胴の左上の穴** (8 番ピン)。1 番ピンはその 3 行下の左下
(`h4`) で、下の列を右へ 1〜4、折り返して上の列を左へ戻って 5〜8 と並ぶ
(切り欠きを左にした実物を上から見た番号の付き方)。2 列の間隔は
**300 mil = 3 穴**。図の左端の切り欠きが 1 番ピン側の目印で、
これが無いと図を見ながら 180 度回して挿せてしまう。

**3 ピンは穴を 3 つ書く。** ピンは曲げられるので、列に並べても三角に開いても
挿さる — どちらで書いたかを図に出したい。

ピンの名前は `部品名.番号` で、**番号は書いた順** (DIP と SIP はパッケージの順)。
ネットリストにはこの名前が出る。

SIP (片側だけの列) も同じくアンカーを 1 つ書く。dip と違って**奇数でよい**。

## 3 ピンの IC (`ic3`)

ホール素子・温度センサー・メロディ IC のような**ピンの名前が品ごとに違う
3 ピンの IC** は `ic3` で書く。置き方はトランジスタと同じで、ピンは書いた順に
`1` `2` `3`。姿は `to92` (既定) と `to220`。

```circuit
title: 回路図03 温度センサー (LM35)
parts:
  V1: vsource 2,2 2,5 5
  VCC: vcc 2,2 5V
  G1: ground 2,5
  U1:
    type: ic3
    at: 6,3
    label: LM35
    pins: [+Vs, Vout, GND]
  OUT: port 6,5
  G2: ground 8,3
wires:
  - 2,2 -- 4,2
  - U1.1 -| 4,2
  - U1.2 -- 6,5
  - U1.3 -| 8,3
```

回路図 (` ```circuit ` の `pins:`) か本文で示す。
