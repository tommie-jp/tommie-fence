# IC と 3 本足の部品

DIP と SIP は**アンカーを 1 つだけ書く**。足の位置はパッケージが決めていて、
書く人が選べないため — 8 個の穴を書かせるのは、選べないものを書かせること。

**配線は網ごとに色を分けてある** — 赤が +、黒が GND、残りを黄と白に振った。
同じ色の線は同じ網で、色が違えば別の網。交差する線は跨いで引くが、**跨ぎだけでは
「どの線がどこへ行くのか」までは追えない**ので、色で網をたどれるようにしてある
(実物でも被覆の色を分けて挿し、赤と黒は電源に取っておく)。

**基板の図の前に回路図を置く。** 実体配線図だけでは「なぜその穴なのか」が
読めないので、先に回路を見せてから板に落とす。回路図は
[circuit-fence](../../circuit-fence/) の ` ```circuit ` フェンスで、
図は `npm run schematics --workspace=perfboard-fence` で作り直す
(描くのに TeX が要るので、板の図とは別の工程になっている)。
**2 つの図のネットリストは同じ**になる — 違っていたら、どちらかが間違っている。

```circuit
title: 回路図01 NE555 の非安定マルチバイブレータ
parts:
  VCC: port b1
  U1: dip8 e5 NE555
  G1: ground g3
  R3: resistor f2 h2 330
  D1: led h2 j2 red
  G3: ground j2
  C2: capacitor h6 j6 10n
  G2: ground j6
  R1: resistor b10 d10 10k
  R2: resistor d10 f10 47k
  C1: capacitor f10 h10 10u
  G4: ground h10
wires:
  - b1 -- b10
  - U1.4 -| b1
  - U1.1 -| g3
  - U1.3 -| f2
  - U1.2 -| g4
  - g4 -- g9
  - g9 -- f9
  - U1.8 -| b7
  - U1.7 -| d8
  - d8 -- d10
  - U1.6 -| f9
  - f9 -- f10
  - U1.5 -| h6
style:
  grid: on
```

`dip8 c4` の `c4` は**1 番ピン**。そこから右へ 1〜4、折り返して下の列を
左へ戻って 5〜8 と並ぶ (実物の番号の付き方そのまま)。2 列の間隔は
**300 mil = 3 穴**。図の左端の切り欠きが 1 番ピン側の目印で、
これが無いと図を見ながら 180 度回して挿せてしまう。

**3 本足は穴を 3 つ書く。** 足は曲げられるので、列に並べても三角に開いても
挿さる — どちらで書いたかを図に出したい。

```circuit
title: 回路図02 エミッタフォロワ
parts:
  VCC: port a1
  VR1: potentiometer a2 c2 10k
  G1: ground d2
  Q1: npn b4 2SC1815
  R1: resistor c4 d4 1k
  G2: ground d4
  OUT: port c5
wires:
  - a1 -- a4
  #- b3 -- c3
  - c2 -- d2
  - VR1.w -- b3
  - b3 |- Q1.B
  - a4 |- Q1.C
  - Q1.E -| c4
  - c4 -- c5
style:
  grid: on
```

足の名前は `部品名.番号` で、**番号は書いた順** (DIP と SIP はパッケージの順)。
ネットリストにはこの名前が出る。

SIP (片側だけの列) も同じくアンカーを 1 つ書く。dip と違って**奇数でよい**。
