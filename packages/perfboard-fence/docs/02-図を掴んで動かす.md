# 図を掴んで動かす

図を見ながら部品や穴を掴んで動かし、フェンスの番地を書き換える操作。
**位置を穴番地で書く**フェンスなので、「動かす」は行の中の綴りを
差し替えるだけで済む。

**操作は 3 つのフェンスで同じ** (KiCad 流。鍵・手つき・画面の配置)。
共通の操作は fence-kit の
[docs/01-図を掴んで動かす.md](../../fence-kit/docs/01-図を掴んで動かす.md)
にまとめてある。ここに書くのは **perfboard での違い**だけ。

## 2 つの入口

| 開き方 | どうなるか |
| --- | --- |
| タブの頭の一覧から `perfboard Editor` | `.md` のタブそのものが図のエディタになる |
| `Perfboard Fence: 図を掴んで動かす (マップ)` | エディタの横にマップを開く |

## 掴むのは図そのもの

マップは**別に描いた升目ではなく、図そのもの**。穴の上に透明な当たり判定が
重なっているだけなので、見えている絵と掴む場所が食い違わない。

## 置く (この板での穴の並べ方)

`A` で種類を選ぶと、押した穴を 1 つ送るだけで**残りの穴はこちらが並べる**。

| 種類 | 押した穴から |
| --- | --- |
| 2 本足 | 同じ行の右へ、既定の間隔 (抵抗 5 穴、LED 1 穴、ほか 3 穴)。ドラッグすれば間隔を選べる |
| 3 本足 (トランジスタなど) | 同じ行の右へ 2 穴 (`b2` → `b2 b3 b4`) |
| DIP / ピンヘッダ | 押した穴が 1 番ピン (足の位置はパッケージが決める) |

- **右へ入らなければ断る** (左へ折り返さない — 押した場所で向きが変わる規則に
  しない)。「右へ 2 穴ぶん要ります」と言う。この板はレールが無く全穴が独立
  なので、断るのは板の外だけ
- 足の印は書かない。ピン配列は型番の話なので、書く人が付ける
- 名前は**接頭辞ごとに最小の未使用番号** (DIP は `U`、ピンヘッダは `J`)
- **パレットに出るのは実物として売られている数**だけ (`dip8` `sip4` など)。
  ほかの数も種類の欄に打てば置ける
- **板に収まらない置き方は断る。** DIP は書いた穴より足が広がるので、
  はみ出す所に置こうとするとゴーストが赤くなる

## 回す・反転する

`R` で時計回り、`Shift+R` で反時計回り、`X` で反転。**掴んだ物によって行の
直り方が変わる**が、押す側から見ればどちらも 1 つの操作。ゴーストにも効く。

**足を並べて書く部品 (2 本足・3 本足)** — 穴の番地が動く。

- **アンカー (先に書いた足) は動かない。** 動かすと「回す」が「移動」になる
- 反転は**足の並びの入れ替え**。書かれた綴りをそのまま入れ替えるので、
  手で整えた空白も残る。3 本足なら両端が入れ替わり、真ん中はその場に残る
- 板の外へ出る回転は、**どの穴が出るのかを名指して**断る

**アンカー 1 つで置く形 (DIP / SIP)** — 向きの語が直る →
[部品の向き](01-syntax.md#部品の向き-r90--r180--r270--mirror)

- 語は**穴のすぐ後ろ**に入る (`U1: dip8 c3 r90 NE555`)。値は最後のまま
- 一周して元の向きに戻ったら語は消える (**前の空白ごと**消えて、行末に余りが残らない)
- 回転と反転は別々なので、回してから裏返しても回転は残る
- **回した先が板の穴に落ちることを見る。** 落ちない図は描けないので、
  掴んで回した人に帯だけが残らないよう、ここで断る

## 名前・種類・値を直す

部品を選ぶと左に欄が出る。`Enter` か欄を離れたときに行へ当たる。

- **名前**を変えると、鍵と**その部品を指す注釈**が一緒に変わる
- **種類**は置く前に確かめる (知らない種類は断る)
- **値**は `#` や YAML の記号を通さない — 行の形が壊れて値が黙って消えるため。
  **ラベルの欄は無い** (この文法に `l=` にあたる綴りが無く、字を添えたいときは
  注釈で書く)
- **足の数が変わる種類には替えない。** 穴の数が合わなくなると図が消える

## 部品を動かす

**最初の穴がアンカー**で、部品は形を保ったまま平行移動する。値も名前も触らない。
板の外へ出る移動は断る。

## 節点を動かす

その穴に来ているものを丸ごと運ぶので、**接続は保たれる**。`points:` で
名前が付いていれば、直すのは普通はその行き先の 1 行だけ。

**縮退は断る。** 寄せた先に自分のもう一方の足がある部品は長さ 0 になり、
図から消えてしまう。その組み合わせは動かす前に名指して断る。

## 接続が変わったら教える

**動かす前に止めない。** 移動の前後でネットリストを比べ、**離れた接続と、
つながった接続を動かしたあとに**状態行へ並べる。全穴が独立なので、
1 穴動かせばたいてい何かが変わる。部品を消して配線が残れば、帯の ERC が
「つながっていません」と教える。

## 板から張り出す部品

端面実装のコネクタ (`sma/female-edge`) は、**足が板の縁の外にあるのが正しい姿**。
選ぶ・動かす・引きずる・回す・消すは、ほかの部品と同じようにできる。

**ほかの部品の足は穴の中だけ。** 抵抗を板の外へ動かそうとすると断る —
足の行き先は穴なので、外に出ると挿す所が無い。

## スロットの銅箔へつなぐ

`slots:` を書いた板では、**縁の銅箔も押せる**。穴の並びのすぐ外の番地
(`a0` や `a13`) がその銅箔で、配線の端として引ける — 実物のスロットは
電源を引き回すために付いているので、半田付けする先として正しい。

**部品は挿さらない。** 銅箔には穴が無いので、置こうとすると断る。

## いまできないこと

**配線を折る綴りが無い** ので、`Shift` を押しても配線はまっすぐのまま
(案内にも出ない)。

**フロー形式 (`parts: {R1: …}`) の行は消せない・足せない。** その書き方では
行が 1 つのものに対応しないので、行ごと消すと鍵まで消える。動かすほうは
今までどおり効く。

## 書き換え方

**YAML を組み直さない。** 行の中の穴の綴りだけを差し替えるので、
手書きのコメント・整形・並び順がそのまま残る。
