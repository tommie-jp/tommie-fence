## [Unreleased]

### Changed

- **領域で囲んでまとめて選べるようになった。** 何も無い所から引くと帯が出て、
  中心が入った部品を全部選ぶ。**動かす・回す・反転・複製・消す**が選んだ全部に
  効く。

  **書き換えは 1 回にまとめる** — 1 つずつ当てると、戻すのに選んだ数だけ
  押すことになる (選んだのは 1 回なので、戻すのも 1 回であるべき)。
  途中で断られたものは飛ばして続け、**何件できなかったかを言う**。

  動かすときは**押した部品の動きをほかにも掛ける**。行き先は 1 つしか
  来ないので、その差だけ全部をずらす。

- **パレットに部品の姿が出るようになった。** 名前の前に実物の姿を置く。
  以前は「小さな枠に落とすと読めない別物になる」として出していなかったが、
  **胴はもともと小さい** (抵抗で 38 × 13) ので縮めずに置ける。
  **図と同じ関数で描く**ので、姿を直すとパレットも一緒に直る。

- **主なフットプリントを一通り足した。** 実物で姿の分かれるものを、
  姿として選べるようにした (`resistor/half` のように書く)。

  | 種類 | 姿 |
  | --- | --- |
  | `resistor` | `quarter` (1/4W) / `half` (1/2W)。実物なりに胴が大きくなる |
  | `diode` / `zener` / `schottky` | `do35` (ガラス管) / `do41` (黒いプラスチック) |
  | `inductor` | `axial` (芯に巻いた軸物) / `radial` (樹脂で固めた立てた缶) |
  | `potentiometer` | `trimmer` (ねじで回す半固定) / `knob` (軸の立つボリューム) |

- **属性パネルの種類の欄で姿を選べるようになった** (`crystal/cylinder`)。
  候補に姿つきの綴りも並ぶので、姿を変えるためだけに本文へ戻らずに済む。

- **言うことの行番号を Markdown の行にした。** これまでフェンスの中の数え方で
  出していたので、書き手が Markdown の何行目かを数え直すことになっていた
  (実機で指摘された)。プレビューでも CLI でも `.md` の行番号で出る
  (`.yaml` を丸ごと 1 枚として描くときはそのまま)。

- **配線を選ぶと、左の属性パネルで色を選べるようになった。** これまで配線は
  行が光るだけで、色を変えるには本文を直すしかなかった。**空にすると色の語ごと
  消える**ので、図の既定の色に戻すのも同じ欄でできる。
  掴み手は書かれた行 (注釈と同じ考え方で、名前の無いものは行で指す)。

- **ゴーストの絵が穴からずれることがあったのを直した。** 絵と穴を**重心**で
  合わせていたが、足の並べ方は板が決めるので、板の端では左へ伸びたり右へ
  伸びたりする。伸びる向きが変わると重心がずれて、絵が穴から離れた。
  **アンカー (先頭の穴) で合わせる** — 置くのも動かすのもアンカーが押した穴に
  来る決まりなので、そこを合わせれば必ず揃う。

- **`text` の注釈の書き方を 3 つのフェンスで揃えた。**
  `- text 番地 [語]: 字` の 1 つの形にする。語は**色と向き**で、順不同。
  向きの語 (`r90` / `r180` / `r270` / `mirror`) も 3 つで同じ綴り。
  **perfboard だけ書き方が違った** (`- text 番地 言葉…` で、字が番地のあと
  全部)。字と語が分かれていなかったので色も書けず、向きは種類のほうに `/` で
  書くしかなかった。`:` で分けたので、**`text` にも色を書ける**ようになり、
  向きもほかと同じ語の並びに入った。**古い書き方は読めなくなる** —
  `- text c3 ここ` は `- text c3: ここ` に直す。

- **道具の絵とマップの色を、テーマのグラフ色から実色に変えた。** グラフの
  系列色は明るいテーマだと淡く出て、橙が黄色に寄って読めなかった (実機で
  「黄色は見にくい」と指摘された)。白地でも黒地でも読める濃さに決め打ちした。
  カーソルの下の印も同じ橙だったので、あわせて直した。

- **道具の絵に色が付いた。** 白黒の絵が 9 つ並んでいて見分けにくかった。
  **意味の同じ道具は同じ色** — 増える (部品・複製) が緑、つなぐ (配線) が青、
  動く (動かす・引きずる) が橙、向きが変わる (回す・反転) が紫、
  減る (消す) が赤。9 つに 9 色を配ると、色そのものが手がかりにならない。
  右クリックの一覧も同じ色にする。

- **`text` の注釈に向きを書けるようになった** (`text/r90 f6 ここから電源`)。
  書ける語は部品と同じ `r90` / `r180` / `r270` / `mirror`。
  **向きは種類のほうに `/` で書く** — `text` は番地のあとが全部言葉なので、
  そこに語を置くと「`r90` で始まる注釈」と区別が付かない (色を `text` に
  書けないのと同じ理由)。回るのは**指す穴のまわり**で、`mirror` は字を
  裏返さず**指す穴の反対側へ移す** (鏡文字は読めない)。

- **注釈 (`notes:`) を掴めるようになった。** 選ぶ・動かす・複製する・消す・
  言葉を直すが、部品と同じ手つきでできる。**掴み手は書かれた行** — 注釈には
  名前が無いので、行そのもので指す (配線と同じ考え方)。
  2 点で形が決まる注釈 (`box` / `arrow`) は**両方の穴が一緒に動く**ので、
  動かしても形が変わらない。**回す・反転するは `text` だけ** —
  印や枠には向きが無いので、理由を言って断る。

- **メニューから選んだ部品も、置く前に実物の姿で見えるようになった。**
  行き先の穴を光らせるだけでは何を置こうとしているのか読み取れなかった。
  動かすときと同じ見え方に揃えた (置けないときは赤く濁る)。
  **名札も置いたときに付く名前で出る。**

  図にまだ無い部品なので、試し当てで作った写しの図から切り出して渡す。
  **姿が変わったときだけ組み直す** — 場所を変えただけなら前の絵をずらすので、
  穴をまたぐたびの重さは増えない。

- **図に書き出せるフェンスの行数を 80 行から 1000 行にした。** 項目ごとの上限を
  全部使い切るとフェンスは 1000 行を超えるので、80 行では自分の図の書き出しさえ
  切れていた。709 行のフェンスで 0.06 秒・530KB と測れたので、重さは問題にならない
  (circuit は 1 行ごとに TeX の節点が増えるぶん重く、309 行で 6.8 秒)。

- **CLI に `--version` が付いた。** 版を答えて終わる (図に刻むなら
  `style: stamp: on`)。circuit にしか無かったものを 3 つに揃えた。

- **CLI が空のディレクトリを黙って通さなくなった。** `.md` も `.yaml` も無い
  指定を渡した CI が、何も検証しないまま緑になっていた (perfboard にしか
  入っていなかった守りを 3 つに揃えた)。

## [0.3.0] - 2026-09-04

### Changed

- **`slots:` を書いた板は、銅箔にも番号を出すようになった。** 番号が `0` から
  `列数 + 1` まで伸びる (縦長の板なら行のほうが)。銅箔には配線を半田付けできる
  のに番号が出ていなかったので、端をどう書けばよいか図から読めなかった。

- **運んでいる部品の姿を行き先に出すようになった。** 穴を光らせるだけでは
  何が来るのか読み取りにくかった (実機で指摘された)。掴んだ部品の絵をそのまま
  写して行き先へずらし、置けないときは赤く濁らせる。持ち上げた元の絵は薄くする。
  **描き直さずに写す**ので、穴をまたぐたびの問い合わせは増えない。

- **回す軸を足の真ん中にした。** 先に書いた足を軸にしていたので、回すと胴が
  大きく振られて「移動」に見えた。KiCad の `R` も選んだものの中心を軸にする。
  **置く前の回しは押した穴が軸**のまま (押した穴に足が来るのが置くときの約束)。
  `points:` の名前で書かれた足があるときはそこが軸 — 名前は場所を指す約束なので、
  動かすと番地に直すしかなくなる。

- **平たい缶 (HC-49) の足の出口を中心線の左右にした。** 缶の下の角から出ている
  絵になっていたが、足の穴は 2 つとも中心線の上に並ぶので、足はそこへ向かって
  缶の両端から出る (実機で指摘された)。

- **道具の「動かす」と「引きずる」が何に効くのかをボタンに書いた。** どちらも
  「持ち上げて 1 クリック」で形が同じなので、名前と鍵だけでは一覧で見分けが
  付かなかった (実機で「何が違うのか」と訊かれた)。右の道具の列でも
  右クリックの一覧でも、指すと相手が出る。

## [0.2.1] - 2026-09-04

### Fixed

- **「回す」で 3 本足の胴が回りきらなかった。** 足の並びの**傾き**だけを見て
  縦横を決めていたので、180 度回しても TO-92 の平らな面が上を向いたままだった。
  **1 番ピンから最後のピンへ向く向き**で数えるようにして、`R` を押すたびに
  平らな面が 4 方向を回るようにした。向きは**画面の座標ではなく番地**で数える —
  半田面 (裏返した板) は列を反転して描くので、点の差だと裏だけ 180 度ずれる。

- **水晶の穴と穴を結ぶ線を消した。** 2 本足の部品は胴の両端から足が出るので
  穴を結ぶ線を引いていたが、**水晶の足は缶の下から出て穴へ下りる**ので、
  穴を渡る水平な線は実物に無い (実機で指摘された)。

- **平たい缶 (HC-49) を上から見た姿にした。** 缶を立てて正面から見た絵になって
  いたが、この図はどれも上から見た姿。実物は幅 11mm・足の間隔 4.88mm なので、
  **缶は足の穴を覆う**。缶より広い間隔に挿したときだけ、缶から穴まで足が伸びる。

## [0.2.0] - 2026-09-04

### Added

- **図を掴んで動かせるようになった。** `.md` のタブの頭の一覧から
  `perfboard Editor` を選ぶとそのタブが図のエディタになり、
  `Perfboard Fence: 図を掴んで動かす (マップ)` で横にも開ける。
  **掴むのは図そのもの** — 別の升目ではなく、穴の上に透明な当たり判定が
  重なっているだけ。書き方は
  [docs/02-図を掴んで動かす.md](docs/02-図を掴んで動かす.md)。

  **置く・動かす・消す・つなぐ・名前や値を直す**までできる。パレットは
  **種類名・略記・和名**の 3 通りで探せ、名前は**接頭辞ごとに最小の未使用番号**が
  付く。

  **回す・反転する** のは `R` と `M`。**足を並べて書く部品 (2 本足・3 本足)** は
  向きが穴の順そのものなので、番地が動くだけで文法は変わらない。
  **アンカー 1 つで置く形 (DIP / SIP)** は下の「部品の向き」を参照。
  板の外へ出る移動と回転は、**どの足が出るのかを名指して**断る。

  **ERC のお知らせと読めなかった行が同じ帯に出て、押すとその行へ飛ぶ。**
  繋ぎ忘れが図の上で沈黙する板なので、直す場所を編集する場所と同じ窓に
  出す値打ちが大きい。

  **YAML は組み直さない** — 行の中の綴りだけを差し替えるので、手書きの
  コメントも整形も並び順もそのまま残る。マップの殻は `fence-kit` にあり、
  circuit-fence / breadboard-fence と**同じものが動く**。

- **部品の向きを書けるようになった (`r90` / `r180` / `r270` / `mirror`)。**
  `U1: dip8 c3 r90` と穴のすぐ後ろに書く。**アンカー 1 つで置く形
  (`dipN` / `sipN`) だけ**が語を持つ — 足を並べて書く部品の向きは穴の順
  そのものなので、語を足すと同じことを 2 通りで書けるようになる。
  **語彙と意味は circuit フェンス・breadboard フェンスと同じ** (時計回り、
  反転してから回す)。同じ種類を 2 回書いたら断る。
  → [docs/01-syntax.md](docs/01-syntax.md#部品の向き-r90--r180--r270--mirror)

  **回した先が板の穴に落ちることを見る。** 板の外の番地は穴ではないので、
  そこへ足が来る図は実物では組めない。**回すと縁を踏みやすい**ので必ず見て、
  はみ出した足を名指して断る (端面実装は先端が板の外に出るのが正しいので除く)。

  描画は 1 行も変えていない。perfboard の箱はピンから組んでいるので、
  足が回れば箱も切り欠きもキャプションも付いてくる。
  マップで掴んだときも 1 つの操作で通る — `R` と `M` が語を書き換える。

### Fixed

- **TO-92 が D 形になっていなかった。** 丸を描いたあと、平らな面の内側を**胴と同じ
  色で**塗っていた。同じ色では丸は削れないので、弦が 1 本乗った丸のままだった。
  輪郭そのものを D のパスで描くようにした。

- **3 本足の胴が足の並びに沿っていなかった。** 全穴が独立している板なので 3 本足を
  縦にも挿せるが、胴は横向きのまま描いていた。TO-92 の平らな面が足の 1 本を向く、
  実物ではありえない向きになっていたので、**足の軸で胴を回す**ようにした。

- **選んだ部品が図の上で分からなかった。** 選択の印は circuit の記号マップ向けに
  書かれていて、部品の中の線を塗り替えるだけだった。perfboard の部品は**実物の姿
  そのもの**で塗り替える線が無いため、選んでも図が何も変わらなかった。
  焦点色で**光らせ**、まわりを**破線の枠で囲む**ようにした (枠の当たり判定は外して
  あるので、枠の上でも部品を掴める)。

- **横置きの SMA の中心導体が、書かれた穴まで伸びていた。** 板の奥の穴に書くと
  長い棒の付いた部品に見えた。**実物の長さで描く** — アースの腕より先へ出す分だけ
  出して、そこで止める (凹んだアースと凸の信号、という見分けは残る)。

- **姿つきの部品を複製できなかった。** 欄に出るのは書かれた綴り
  (`sma/female-edge` や `capacitor/electrolytic`) なのに、種類として引くときに姿を落としていなかったので
  「名前を付けられません」で止まっていた。**複製は行を写す形にした** —
  足の並びが形で決まる部品は、置き直すとその並びを作り直せない。

- **板の縁に付けた端面実装のコネクタ (`sma/female-edge`) を動かせなかった。**
  足が板の縁の外にあるのが正しい姿なのに、動かす・回すが「板の外です」と断って
  いた (置く側は通していたので、**書けるのに動かせない**部品になっていた)。
  張り出す形かどうかで規則を分ける — ほかの部品の足は今までどおり穴の中だけ。
  引きずるための点も、板の外の足に立つようにした。

- **`slots:` の銅箔へ配線できなかった。** 手で書いた図では銅箔がつながる場所として
  働いていた (`c2 -- a0` でネットに乗る) のに、マップでは押せず、欄からも断られて
  いた。掴める升を銅箔にも立て、配線の端として通す。**部品は今までどおり挿さらない**
  — 銅箔には穴が無いので、置く先は穴だけ。

- **配線を選べない・消せなかった。** 掴むための太い透明な線に行番号
  (`data-line`) が付いておらず、外の `g` にしか無かった。webview はカーソルの下に
  ある要素からそのまま読むので、掴んでもどの行か分からなかった。掴み手そのものに
  持たせた (3 つのフェンスで同じ印になったことを、契約のテストが見張る)。

- **回した DIP の切り欠きが、パッケージの端に出るようになった。** 箱の左右の
  辺のどちらかに決めていたので、90 度回した DIP では**端ではない辺**に出ていた。
  端は 1 番ピンと最終ピンの間なので、その中点から決めるようにした
  (`dip8` の箱は正方形なので、縦長か横長かでは決められない)。

- **白黒のテーマ (`mono`) で、色が網と線の型に移るようになった。** 配線の色・
  LED の色・抵抗のカラーコードは実物の色なのでテーマでは動かず、白黒の図に
  そこだけ色が残っていた。落とすと今度は「同じ色の線は同じ網」が読めなくなる
  ので、色ごとに線の型 (`stroke-dasharray`) と網 (`<pattern>`) を決め、
  **引き当てる凡例を板のすぐ下に出す**。並ぶのはその図が使った色だけで、
  色を書かなければ凡例も出ない。黒は実線・塗りつぶし — いちばん多く使う色を
  素の形に置くと、網が付いた線だけが「色を書いた線」として目に立つ。

- **部品表を出せるようになった** (`notes: - parts`)。番地と値は図の中に散らばって
  いるので、何を揃えればよいかは図を目で追うしかなかった。同じフェンスから出す
  ので、部品を足したのに表を直し忘れる、が起きない。**抵抗にはカラーコードを字で
  添える** (`10k` → `茶黒橙茶`) — 実物を選ぶときに見るのは帯の色そのものだが、
  図の帯は小さく白黒で刷ると消える。値として読めない抵抗には出さない。
  板の外の機器も並ぶ。`- source` と一緒に書いたときは部品表が上、書き出しが下。
- **コンデンサの姿を描き分けるようになった。** 積層セラミックは青い小判、
  フィルムは黄の箱、タンタルは橙の小判、アルミ電解は黒い缶に縁の輪。
  これまでは姿を書いても「まだ描き分けません」と言うだけで図は同じ形だった。
  **アルミ電解にだけ 3 桁コードを刷らない** — 実物の缶に出ているのは容量
  そのもので、刷ると図が実物と違うことを言う。

- **途中で交差する配線を跨いで引くようになった。** この板は導通が配線の両端の
  穴だけで生まれるので、線の途中の交差では何も起きない。ところが図では 2 本が
  同じ点で出会って**半田付けした接点に見える**ので、あとに書いたほうを半円で
  跨がせた。端が別の線の途中に乗っているもの (T 字) は跨がない — そこは交差では
  なく書き方の問題で、跨いでも読めるようにはならない。
- **半田面の重ね順を、手前から 半田点 → 配線 → 部品 にした。** 半田面で見るのは
  半田付けする穴とジャンパで、部品は板の向こう側にある。部品は薄く敷いて
  「どのランドがどの部品の足か」だけを伝える。
- **機器 (`device`) の足の名前を大きくした。** 配線をどの端子へ引くかを読むのは
  この字で、`+` `-` `1` `2` のように短いので板の字と同じ大きさだと線と穴に
  埋もれる。**隣の名前とくっつかない大きさまで**で頭打ちにし、箱の幅も名前が
  並ぶ幅から決めるようにした (`sig gnd` が 1 つの綴りに読めていた)。
- **斜めに置いた部品のキャプションも、胴と同じだけ傾けるようになった。**
  縦置きの 90 度だけだったものを任意の角度に広げた。上下がひっくり返る向きへは
  回さない。
- **板の縁に載せた SMA のアースに接点の印を出すようになった。** 凹の 2 本の腕が
  板を挟むところが半田付けする場所で、アースは穴に挿さらないぶん埋まる穴も
  出ないため、印が無いとどこを付けるのか図から読めなかった。
- **3 本足の部品と DIP / SIP を置けるようになった。** 3 本足 (`transistor`
  `potentiometer` など 6 種) は穴を 3 つ書く — 足は曲げられるので、列に並べても
  三角に開いても挿さり、どちらで書いたかを図に出したい。
  `dipN` / `sipN` は**アンカーを 1 つだけ**書く (足の位置はパッケージが決めていて、
  書く人が選べない)。DIP の 2 列の間隔は 300 mil = 3 穴、番号は実物と同じ
  付き方で、図には 1 番ピン側の切り欠きを描く。
- **板の外の機器を書けるようになった** (`device`)。電池・スピーカー・測定器の
  ように**盤面に載らないもの**を、板の上下の帯に箱として置く。`parts:` の中に
  入れ子で書き (足の名前の並びを持つので 1 行に畳めない)、配線からは `BAT.+` の
  形で指す。**機器へつなぐ配線は、その足から穴まで線を引く** — 電池の線も実物では
  板の穴に半田付けするので、どの穴へ行くのかが図に出ないと、帯に浮いた箱と板が
  結び付かない (breadboard-fence も同じように引く)。色を書けばその色で引く。
  つなぎ忘れた足は部品と同じように ERC が名指す。**機器どうしを結んだ配線だけは
  板に触れない**ので線が無く、色を書いたときはその旨のお知らせが出る
  (黙って消すと、効かない指定を書き続ける)。
  足は `pins: + -` と空白区切りで書ける (YAML の並びに書くと `-` に続く空白が箱の
  始まりに読まれて `["+", "-"]` と括らされるため)。
- **注釈を書けるようになった** (`notes:`)。`mark` (丸)・`box` (枠)・
  `arrow` (指し棒)・`text` (字) の 4 つで、図に印を付けて文章から指せるように
  する。**回路の一員ではない**ので、ネットにもネットリストにも出ない。
  一番上に描く (指したものが下に隠れると印の意味が無くなる)。
  **`text` には色を書けない** — 字は残り全部を言葉として取るので、色を許すと
  「色の名前で始まる注釈」が黙って色になる。
- **テーマと幅を選べるようになった** (`style:`)。`light` / `dark` / `mono` と、
  書き出す画の幅、お知らせを伏せる `debug`、版を刻む `stamp`。
  名前 1 つだけなら `style: dark` と書ける。`debug` と `stamp` は `on` / `off`
  で書ける (YAML 1.2 ではこの 2 語は真偽値ではなく字なので、受けないと
  **書き方として案内した綴りを断る**ことになる)。**配色だけがテーマで動く** —
  寸法は 3 つとも同じなので、テーマを変えても部品の位置も線の通り道も動かない。
  地を変えるテーマ (`dark` / `mono`) は自分の地を塗る (板の外の字が、貼った先の
  背景に紛れて消えないように)。**`debug: off` で伏せられるのはお知らせだけ**で、
  読めなかった行はこの切り替えの対象ではない。
- **フェンスの中身を図に書き出せるようになった** (`notes: - source`)。
  そのフェンスを囲みごと図の下に写すので、**図だけを貼られた人が同じ図を
  もう一度出せる**。番地は書かない (フェンス全体は板より高いのが普通で、
  板に重ねると穴も部品も読めなくなる)。**行番号は添えない** — 値打ちは見たまま
  書き写せることなので、番号が混ざると写したものが動かない。板より横に長い
  書き出しでは切らずに**画布のほうを広げる** (細い板で `…` だらけにしない)。
  色を書かなければ図の文字色に従うので、白黒 (`mono`) の図で書き出しだけが
  浮かない。長いフェンスは途中で切り、**切ったことを図に書く**。
- **ERC を外せるようになった** (`style: check: off`)。回路の一部だけを描いた図など、
  **未結線が承知のうえ**のときに使う。**既定は掛ける** (`on`) — 全穴独立の板では
  繋ぎ忘れが図の上で沈黙するので、見張りを外すのは書いた人がそう言ったときだけ。
  `debug: off` との違いは**伏せるか、そもそも見ないか**で、`check: off` は検査を
  掛けないので呼び出し側にもお知らせが渡らない。図はどちらでも同じ。
- **穴の名前を出す辺を選べるようになった** (`style: labels: sides:`)。
  `left` `right` `top` `bottom` を空白で並べるか、`all` / `none`。
  **既定は左と上だけ** — 四辺に出すと小さい板では名前のほうが目立つ。
  出す辺には余白を空けるので、右と下に出しても字が画布から切れない。
- **板の外の名前を選べるようになった** (`style: labels:`)。行と列に英字と数字の
  どちらを振るかを軸ごとに選べ、英字の大小も選べる。手元の板のシルクに寄せて
  見比べるためのもので、**番地の書き方は変わらない** (`c3` は c 行 3 列のまま)。
  既定は行が英字・列が数字で、今までの図と同じ並び。
- **半田面を出せるようになった** (`style: back: on`)。裏返した板を図の下に足す。
  縁の銅箔も裏返した板に出る (板そのものの持ち物なので、表と同じ場所にある)。
  配線を裏で半田付けするとき、頭の中で裏返すのは間違えやすい (1 番ピンの側を
  取り違えると、直すのに全部剥がすことになる)。入れ替わるのは列だけで、
  字は裏返さない。**既定は出さない** (図の高さが倍になる)。

- **配線と注釈に `#RRGGBB` の色を書けるようにした。** 名前 (12 色) はそのままで、
  手元の被覆の色に寄せたいときは `- b3 -- b6 #ff8800` と書ける。**そのどちらでも
  ない綴りは今までどおり書式エラー** — 色は SVG の属性へそのまま流れるので、
  名前か、字面が厳密に色である綴りかの 2 通りだけを通す。
- **スロット用の銅箔を描けるようにした** (`board:` のマップ形式に `slots: on`)。
  実物の板の**短いほうの両端**に並んでいる細長い銅箔で、列が多い板では左右、
  行が多い板では上下に出る。**穴ではないので挿せず**、番地も持たず、ネットにも
  ネットリストにも出ない。**既定は描かない** — 銅箔の無い板のほうが多く、
  無い板に描くと「そこに何か付けられる」と読めてしまう。穴からは**穴 1 つぶん
  離して**置く (詰めると穴の列の続きに見える)。板をマップで書くときは
  `size:` に大きさが要る (当てて描くと、書いていない板の図が黙って出る)。

- **インダクタの胴にも 3 桁コードを刷るようにした** (`100u` なら `101`。µH 基準)。
  実物には色帯のものもあるが、**帯にすると抵抗と見分けが付かない** — 同じ形の胴なので、
  色だけの違いでは読めない。
- **機器の足の名前を箱の内側に書くようにした。** 外に出すと板の列番号や配線に
  重なり、どの足の名前かも遠くなる。
- **板の外の機器を番地で置けるようにした** (`at: -e1` のように)。番地で置いた機器の
  **足は穴の格子に載る** (1 本目が書いた番地の列、次が 1 穴どなり) ので、
  「その足のいちばん近い穴」が迷いなく決まり、そこから板の上を配線できる。`top` / `bottom`
  なら今までどおり帯に並び、番地を書けば**箱の左上がその番地**に来る。帯に並べると
  置きたかった場所と関係なく散るので、並べ方を自分で決めたいときに使う。
  **機器のはみ出すぶんは板の寸法に入れる** — 入れないと、上は題に、下は書き出しや
  半田面に重なる。
- **縦に置いた部品のキャプションを縦にした** (時計回りに 90 度)。横のままだと、
  細長い部品の脇に長い字が伸びて隣の部品や配線に被る。位置も部品の脇に寄せた。
  箱で描く部品 (DIP・SIP・3 本足) も、縦長なら同じ扱い。
- **足や配線が入った穴を、半田付けした形で描くようにした。** ランドより一回り
  大きい銀の玉で穴を塞ぐ。空いた穴は黒く抜けたままなので、**どこを半田付けするのか
  が図だけで分かる** (同じ形だと、組む人は図とにらめっこして足を数え直す)。
  半田面にも同じ穴が出る。
- **色を書かなかった配線の色を、板の色から選ぶようにした。** 緑や黒の板には
  明るい線、白い板には暗い線。既定を 1 つの灰色に固定すると、同じ濃さの板で
  線が沈む。板の色を変えれば線の色も一緒に動く。**書いた色は動かさない**
  (実物の被覆の色なので、読みにくくても書いたとおりに描く)。
- **板の色・ランドの色・スロットの色を書けるようにした** (`board:` の
  `color:` / `land:` / `slots:`)。板は `green` `blue` `red` `black` `white`
  `yellow` `purple` `bare` と `#RRGGBB`、めっきは `silver` `gold` `copper` `tin`
  と `#RRGGBB`。**板とめっきで表を分けてある** — 混ぜると板に `gold` と書けてしまい、
  綴りは通るのに実物にない板が出る。`slots:` は `on` / `off` のほか色でも書け、
  `land:` だけ書いたときはスロットも同じめっきになる (実物も同じ工程)。
  **色は板の性質**なのでテーマ (`style:`) ではなく `board:` に書く。

- **同軸コネクタ (`sma`) を置けるようになった。** 姿は `male` / `female` で、
  **中心がピンか穴かで描き分ける** (図を見て挿す人が、合う相手を取り違えないように)。
  足は**中心導体と GND の 2 本** — 実物の GND は 4 本だが、図とネットリストで
  意味を持つのは「どこが中心でどこが GND か」の 2 つ。胴は六角の 6.35mm ぶんで、
  **足を広げても伸びない** (玉の部品と同じ扱い)。**横置き** (端面実装) は
  `male-edge` / `female-edge` で、板の縁に載せて首から先を板の外へ出す。
  張り出すのは**GND の側** (実物は GND の脚が縁に来て、中心導体がその内側まで伸びる)。
  姿は外形図と同じ 3 段 — ねじ部・胴・足で、**足がどの穴に入るかまで描く**
  (胴で覆ってしまうと、板の縁に載っているだけの絵になる)。胴には
  **`SMA` / `male` (`female`) と 2 行で姿を書く** — オスとメスは形の細部でしか
  違わないので、字でも言わないと図から買う人・挿す人が取り違える。
  字は胴と一緒に回さない (板の右の縁に載せると鏡文字になる)。
  横置きの胴は**ねじ部・ねじなし・台座 (1mm)** の 3 段で、**台座の右端が板の縁**に
  揃う (実物もそこで板を挟む)。足は凹の形で、上下にアースが伸び、その間から
  中心導体が凸に出る。
- **画布からはみ出す部品ぶん、画布を広げるようにした。** 横置きのコネクタは板の外へ
  張り出すので、板の寸法だけで画布を決めると**図が黙って切れる**。
  キャプションも**足の真ん中**を基準に置くようにした (胴の中心に置くと、板の外へ
  出た部品で字が地に紛れるか、幅ゼロで `…` に切られる)。

- **番地が板の外を指せるようになった。** 列は `0` とマイナス (`a0` `a-1`)、
  行は `0` とマイナスの英字 (`01` `-a1`)。0 を挟んで **…-B -A 0 A B…** と
  間を空けずに並ぶので、板の中と外で数え方が変わらない。**縁の銅箔 (スロット) は
  穴の格子のちょうど 1 つ外**なので、`c0` や `c26` (25 列の板) がそのまま
  その銅箔になり、そこへ配線を引けば**電気的につながってネットに出る**。
  端面実装のコネクタの脚も、これで銅箔に載せられる。
  **離れすぎ (4 つ先より外) は断る** — 無制限にすると番地 1 つで画布を
  いくらでも伸ばせる。板の外に穴は描かない (指せるのは位置で、挿せる穴ではない)。
- **画布は図の広がりから決めるようにした。** 部品の胴だけでなく配線と注釈も、
  さらに**半田面の側も**数える (裏返すと張り出す向きが逆になるので、表だけ見て
  決めると裏の板でコネクタが切れる)。

- **抵抗のカラーコードを 4 帯・5 帯・6 帯にした。** 帯の本数は**値の桁数**で決まる —
  2 桁で書ける値は 4 帯 (数字 2 + 乗数 + 許容差)、3 桁要る値は 5 帯、温度係数を
  書いたら 6 帯。実物も E24 が 4 帯・E96 が 5 帯なので、書いた値がそのまま帯になる。
  **既定の許容差は ±1% (茶)** — 金属皮膜 (金皮) の標準。値のうしろに `5%` や
  `50ppm` と書ける。色を持っていない許容差・温度係数は帯を描かない
  (近い値へ丸めると、実物と違う帯が出る)。
  帯は実物なりに太く、**ひとかたまりで胴の真ん中**に置く — 実物の帯は隣り合っていて、
  胴の両端には地の色が残る (端まで広げると帯が縁で切れて見える)。短い胴では
  隙間ではなく**帯のほうを細くする** (隙間を詰めると 2 色が 1 本に見え、読み違いになる)。

### Changed

- **水晶振動子を実物の 2 つの姿に描き分けるようにした。** 出回っているのは
  平たい缶 (HC-49) と細い円筒 (時計用の 32.768kHz などに多い) の 2 つで、
  輪郭がまるで違う。`crystal/hc49` (既定) と `crystal/cylinder` で選ぶ。
  平たい缶は**肩の丸みと下の口金 (足の出口の窪み 2 つ)**、円筒は**上端が丸く
  下端は平ら**で、足が同じ端から出て穴の間隔まで開く。

- **3 本足の部品を実物のパッケージの姿にした。** これまではどれも同じ四角い箱
  だったが、TO-92 は**上から見た D 形** (平らな面がどちらか分かる)、TO-220 は
  放熱タブとねじ穴、半固定抵抗はねじの頭、スライドスイッチは溝とつまみで描く。
  姿は breadboard と共有する (`fence-kit` の `parts/packages.ts`) ので、
  同じ部品が 2 つの板で同じ形に出る。

- **面実装のトランジスタを `transistor/sot23-dip` として置けるようにした。**
  SOT-23 の足の間隔は 0.95mm で 2.54mm の穴には届かないので、実物も変換基板に
  載せてから差す。図も**変換基板ごと 1 つの部品**として描く。

- **「姿はまだ描き分けません」のお知らせを落とした。** 書ける姿はすべて図の形が
  変わるようになったので、お知らせのほうが嘘になっていた
  (`led/3mm` と `led/5mm` は前から描き分けていた)。

- **回路記号に見えていた姿を実物にした。** CdS セルは山が 2 つの折れ線 (`W`) で
  描いていたが、それは**抵抗の回路記号**。実物の受光面は細い帯が何度も折り返して
  いるので、櫛形の抵抗体にした。豆電球もフィラメントを大きな `Λ` で描いていたので、
  ガラス球・巻きフィラメント・ねじ口金にした。

- **コイルと水晶振動子を実物の姿にした。** コイルは回路記号と同じ「線の上の山」
  だったので、**芯に銅線を巻いた胴**に描き直した。水晶は軸物 (両端から足) として
  描いていたが、実物の HC-49 は**缶から下に 2 本足が出る**ので、缶が足の上に立つ
  形にした (缶は足の間隔より横に広い)。

- **部品の姿が実物に近づいた。** ダイオード・ツェナー・ショットキー・
  フォトダイオード・水晶・ブザー・ヒューズ・ランプ・CdS・サーミスタ 3 種・
  バリスタは、**どれも同じ箱**で出ていた (13 種)。breadboard-fence が持っていた
  実物の姿を `fence-kit` へ引き上げて共有した — 胴の形は板に依らないので、
  同じ部品は同じ絵になる。白黒の図では今までどおり網に移る。
  3 本足 (トランジスタなど) はまだ箱。

- **図を掴んで動かす操作を KiCad 流に作り替えた。** 3 つのフェンスで同じ鍵・同じ手つき
  (書き方は fence-kit の
  [docs/01-図を掴んで動かす.md](../fence-kit/docs/01-図を掴んで動かす.md)、
  このフェンスでの違いは [docs/02-図を掴んで動かす.md](docs/02-図を掴んで動かす.md))。
  - **カーソルの下が対象。** 選ばなくても、ホバーしている物に `R` / `X` / `Delete` /
    `M` / `G` / `E` が効く
  - **持ち上げて、置く所で 1 クリック。** `A` (か右の道具の列) で部品を選ぶと
    ゴーストがカーソルに付き、`R` / `X` で向きを決めて 1 クリックで置く。
    置いたあとも同じ種類が付いたまま (`Esc` で抜ける)。**2 本足は既定の間隔**
    (抵抗 5 穴、LED 1 穴、ほか 3 穴) で置け、ドラッグすれば間隔を選べる。
    置けない穴ではゴーストが赤くなり、押す前に理由が出る
  - **`M` は移動、反転は `X`** (KiCad と同じ)。`M` で持ち上げてクリックで置く。
    ドラッグでも動かせる。`G` は節点を引きずる (今までの「節点」道具)
  - **`V` / `N` の道具は無くなった** (KiCad に無い。`V` は `Esc`、`N` は `G`)
  - **見た目も KiCad の配置** — 右に道具の列、左に属性、下に状態行
    (いまできること・カーソルの下の穴・ズーム)、`A` で浮かぶ選択窓。
    ホイールでズーム、中ボタン (か `Space` + ドラッグ) でパン、`Home` で全体。
    上の長い案内文と図の下の欄は無くなった
  - **矢印**で 1 穴ずつ動かし、**`Ctrl+D`** でもう 1 つ置く (1 穴ずらして次の番号)。
    `Insert` で直前に置いた種類をもう 1 つ
  - **右クリックで道具の列と同じ一覧**が出る (押した所のものに効く)。
    鍵を覚えていなくても全部できる
  - **DIP・ピンヘッダもパレットから 1 クリックで置ける**ようになった
    (実物として売られている数だけ並ぶ。ほかの数は種類の欄に打つ)。
    **板に収まらない置き方は断る** — 書いた穴より足が広がる形なので、
    今まではみ出す所に置くと図から黙って消えていた
  - **手つきが速くなった。** ゴーストは接続の変化を数えず (穴 1 つで 6ms → 0.3ms)、
    同じ本文のときは図を組み直さない (書き換え 1 回につき 2 度来ていた)
  - **3 本足 (トランジスタなど) がマウスで置けるようになった** — 押した穴から
    右へ 2 穴に広がる

- **端面実装のコネクタ (`sma/*-edge`) を 3 本足にした** — 中心導体と、凹の両端の
  先端 (`J1: sma/female-edge c1 b0 d0`)。実物の凹は板の縁を上下から挟んでいて、
  半田付けするのは腕の先端の 2 点で、中心線の上下の行の縁の銅箔に来る。これまでは
  2 本足で GND を中心線の上に書かせていたので、アースの穴が中心導体の真下に埋まり、
  信号線とアースがつながって見えた。**形も腕も変えていない** — 変わったのは足の
  数と位置だけで、接点の印は先端の足の番地の上に出る。凹は 1 つの金物なので、
  **2 本の先端は配線を引かなくても同じネット**に乗り、ERC は自分の足しか乗って
  いないネットを「つながっていない」と数える。胴の軸は足どうしを結んだ線ではなく
  **板の縁に垂直な向き**で決めるので、先端が上下にあっても斜めにならない。
  足を結ぶリードの線は端面実装には引かない (中心導体と先端を結ぶ線に見える)。
  **先端は片方だけ書けばよい** (`J1: sma/female-edge c1 d0`) — 書かなかったほうは
  中心線を挟んで反対側に補う。先端を中心導体と同じ行に書いたときだけ断る。
- **ERC の切り替えを `erc` から `check` に改めた** (`style: check: off`)。
  ERC という略語を覚えていなくても書けるようにするため。3 つのフェンスの
  `style:` にも `board:` にも `check` は無かったので、名前は衝突していない。

- **既定の板を緑にはんだメッキ (銀) にした。** いちばん多い板の見た目に寄せている
  (それまでは生基板のベージュに金色のランドだった)。**板に載る字の色は板の
  明るさから決める**ようにしたので、白い板には黒い字、緑の板には白い字が出る
  (固定にすると、板の色を変えたときにどちらかが必ず読めなくなる)。

- **秋月 A タイプを名前で引けるようにした** (`akizuki-a`、55 列 40 行)。
  商品写真では列を数え違いなく取れず入れていなかったが、**メーカーの外形図**の
  丸を数えて確かめた (図面自身が `2200-Ø1.00NT` と穴数を書いており、
  数えた 55 × 40 = 2200 と一致する)。
- **C タイプの実寸の別名から 72×47.5mm と 72×48mm を外した。** 同じ「C タイプ」
  でも板が違えば穴数が違う — 72×47.5mm (片面ガラス・めっき仕上げ) の外形図は
  27 × 17 の格子で、72×47mm (ガラスコンポジット・日本製、25 × 15) とは別物だった。
  **数えていない綴りに寄せると違う板の図が黙って出る**ので、外して近い板を
  挙げる側に回した。
- **縦に並ぶ名前を中央に寄せた。** 右端で揃えると、桁の違う名前 (`9` と `10`、
  `Z` と `AA`) が左へはみ出して、列の名前と揃わない。
- **英字の名前を大文字にした** (`A` `B` `C`…)。板のシルクが大文字なので、
  図と実物を見比べるときに揃っているほうが読みやすい。
  小文字に戻すには `style: labels: case: lower`。
- **機器へつなぐ配線を図に引くようにした。** それまでは導通だけをつないで線を
  引いていなかったので、電池の線をどの穴へ挿すのかが図から読めなかった
  (breadboard-fence は引いている)。書いた色もそのまま図に出る。

## [0.1.0] - 2026-09-01

**最初のリリース。** ` ```perfboard ` フェンスで、2 本足の部品なら
置いて・つないで・検証して・書き出すところまで動く。

### Added

- パッケージの骨格。` ```perfboard ` フェンスを認識し、読めなかったところを
  行番号つきのカードで返す (Phase 0)。
- **板と穴を描くようになった** (Phase 1)。`board: 28x18` (列 × 行) と書くと、
  その大きさの板が、行の名前 (`a` `b` … `aa`) と列の番号を添えて出る。
  番地は `b3` の形。
- **2 本足の部品を置けるようになった** (Phase 2)。
  `R1: resistor b3 b7 10k` と書くと、2 つの穴を結ぶ線の上に胴が寝る。
  抵抗は値が読めればカラーコードを塗り、LED は書かれた色で光る。
  1 つの穴に 2 本目の足は挿せないので、重なりは行番号つきで返す。
  3 本足・DIP・SIP はまだ。
- **配線を引いてネットリストが出るようになった** (Phase 3)。
  `- b7 -- c5 red` と書くと 2 つの穴をまっすぐ結ぶジャンパが引かれ、
  そこから導通をたどってネットリストが出る。`points:` で穴に名前を付けると、
  配線の端にその名前を書け、ネットの名前にもなる。
  **全穴が独立している**ので、配線を書かないと何もつながらない。
- **ERC が入った** (Phase 4)。図のとおりに組むと動かないところを、行番号つきの
  お知らせで返す。見るのは 3 つ — どこにもつながっていない足、配線で短絡した
  部品、部品の足を 1 つもつないでいない配線。`points:` で名前を付けた穴は
  「基板の外へ出る」意思表示として見逃す。
  **読めなかったところがあるうちは掛けない** (掛けていないことは言う)。
- **当たり判定と足の間隔を見るようになった** (Phase 5)。足の穴が別でも
  **胴が重なる**組を名指す。軸物 (胴の両端から足が出る部品) が実物では
  入らない間隔に置かれていたら、その穴を名指して言う。
- **図に題を付けられるようになった** (`title:`)。
- **CLI が入った** (`perfboard-fence render` / `check`)。`.md` からフェンスを
  取り出して `.svg` に書き出す。`check` は何も書かずに検証だけする
  (読めない行が 1 つでもあれば終了コードは 1)。
- **例と文法リファレンスが入った**。[examples/](examples/README.md) と
  [docs/01-syntax.md](docs/01-syntax.md)。どのフェンスの直後にもその図を貼ってある。
- **板を名前で書けるようになった**。`board: akizuki-c` (短く `c`) や、
  実寸の綴り `72x47mm` `72x47.5mm` `7.2x4.7cm` でも同じ板が出る。
  持っているのは `akizuki-b` (36 列 27 行) / `akizuki-c` (25 列 15 行) /
  `akizuki-d` (17 列 14 行) の 3 つで、**穴数は商品写真から数えた値**。
  数えていない大きさ (`7x5cm` など) は、近い板を挙げて返す —
  **実寸から穴数は計算しない** (縁の余白が板ごとにも辺ごとにも違うため)。
  単位を書き忘れた `board: 72x47` は穴数として読むが、お知らせでそう言う。

### Changed

- `board:` が読めなかったときの報告を、**理由ごとに言い分ける**ようにした。
  綴りが読めないのか、板が大きすぎるのか、知らない名前なのかで直す手が違う。
