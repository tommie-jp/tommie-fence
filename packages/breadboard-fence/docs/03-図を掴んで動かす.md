# 図を掴んで動かす

図を見ながら部品や穴を掴んで動かし、フェンスの番地を書き換える操作。
**位置を穴番地で書く**フェンスなので、「動かす」は行の中の綴りを
差し替えるだけで済む。

## 2 つの入口

| 開き方 | どうなるか |
| --- | --- |
| タブの頭の一覧から `breadboard Editor` | `.md` のタブそのものが図のエディタになる |
| `Breadboard Fence: 図を掴んで動かす (マップ)` | エディタの横にマップを開く |

一覧は `.md` を開いたタブの頭 (`Text Editor ▾`) にあり、`Markdown Preview` や
`Markdown Editor` と並ぶ。古い VS Code では `View: Reopen Editor With...` から。

**既定の開き方は変わらない。** `.md` は今までどおりテキストエディタで開く。
いつもマップで開きたければ、一覧の「Set Default for '*.md'」で選ぶ。

## 掴むのは図そのもの

マップは**別に描いた升目ではなく、図そのもの**。穴の上に透明な当たり判定が
重なっているだけなので、見えている絵と掴む場所が食い違わない。

**掴む物は 2 つ。** 頭の道具で切り替える。

| 道具 | 掴む物 | 動くもの | 接続 |
| --- | --- | --- | --- |
| 選ぶ | 部品 | その部品だけ | 変わる (離れた / つながった接続を動かしたあとに出す) |
| 節点 | 穴 | その穴に来ているもの全部 | 保たれる |

掴む物が違えば意味も違うので、**同じ操作に混ぜない**。

**動かすのはドラッグだけ。** クリックは選ぶだけで動かない (選んだものは
エディタの書いてある場所が光る)。

## 部品を動かす

**最初の穴がアンカー**で、部品は形を保ったまま平行移動する。

```yaml
R1: resistor a5 a10 330
```

`R1` を `c5` へ動かすと `resistor c5 c10 330` になる。値も極性の印
(`b12(A)` の `(A)`) も名前も触らない。

板の外へ出る移動は断る (行は `a`〜`j`、列はボードの穴数まで)。
**レールは行そのものが極性**なので (`+t5` の 2 つ下は `-t5` ではない)、
レールが絡む移動は列だけが動く。

## 節点を動かす

その穴に来ているものを丸ごと運ぶので、**接続は保たれる**。

`points:` で名前が付いていれば、直すのは**普通はその行き先の 1 行だけ**。

```yaml
points:
  vin: a5
parts:
  R1: resistor vin a10 330
wires:
  - +t5 -- vin red
```

`vin` の節点を `c5` へ動かすと `vin: c5` の 1 行だけが変わり、`R1` も配線も
綴りを変えずに付いてくる。**これが `points:` の存在理由**そのもの。
同じ穴を生の綴りでも書いていたら、そこも一緒に運ぶ — 置いていくと接続が
切れて、「丸ごと運ぶ」の約束が破れる。

**縮退は断る。** 寄せた先に自分のもう一方の足がある部品は長さ 0 になり、
図から消えてしまう。その組み合わせは動かす前に名指して断る。

## 接続が変わったら教える

**動かす前に止めない。** 掴んで放すたびに確認が出ると、位置を試しながら
決めるという本来の使い方で邪魔になる。移動の前後でネットリストを比べ、
**離れた接続と、つながった接続を動かしたあとに**帯へ並べる。

**同じ列の 5 穴はつながっている**ので、`a10` から `c10` へ寄っても導通は
変わらない — そのときは何も言わない (言うと嘘になる)。溝をまたげば言う。

`points:` で名前を付けた穴も**接続の相手として数える**。部品が 1 つしか
来ていないネットでも、名前から離れたことは知らせる値打ちがあるため。

## エディタと突き合わせる

マップとエディタは**互いに指し合う**。

- マップで掴むと、その部品 / 節点を**書いている場所がエディタで光る**。
  フォーカスは動かさない — 掴んでいる最中にエディタが前へ出ると、
  マップが隠れて置けなくなる
- エディタのカーソルを動かすと、指しているものが**マップで光る**。
  穴の綴りの上なら節点、それ以外は行が持っているもの (部品か配線)。
  `points:` の行はどこにカーソルがあってもその穴を指す

図の下の帯には、読めなかった行とお知らせが出る。**行を押すとエディタの
その行へ飛ぶ**。編集はどれも間違いを生むので、直す場所を編集する場所と
同じ窓に出している。

## 戻す・やり直す

タブそのものがマップのときは、VS Code の `Ctrl+Z` がそのまま効く。
横に開いたパネルのときは、パネルにフォーカスがあると `Ctrl+Z` が
エディタに届かないので、**パネルが自分で覚えている** (頭のボタンか
`Ctrl+Z` / `Ctrl+Shift+Z`)。

移動したあとにフェンスを手で書き換えていると戻せない。丸ごと書き戻すので、
当てると手で書いた分まで消えるため、黙って当てずに断る。

## いまできないこと

**部品を置く・消す・名前や値を変える**のは、まだマップからはできない
(テキストで書く)。押すと「まだマップからできません」と返る。

## 書き換え方

**YAML を組み直さない。** 行の中の穴の綴りだけを差し替えるので、
手書きのコメント・整形・並び順がそのまま残る。
