# エミッタ接地アンプ (2SC1815, 5V, スピーカー出力)

音声帯域の定番、エミッタ接地 1 石アンプ。電源 5V、入力は 50Ω の音声、
出力は 8Ω の小型スピーカー。ブレッドボードで動作を見るための実験回路。

```breadboard
# 電源: 上下の赤レール = +5V、青レール = GND (左端で上下を渡している)
board: half
parts:
  # 増幅段
  Q1: transistor h9(B) h10(C) h11(E) 2SC1815
  Rc: resistor j10 j5 100
  Re: resistor j11 -b11 27
  C2: capacitor f11(+) f15(-) 470uF
  # バイアス (上ブロック)
  R1: resistor d12 d16 3.9k
  R2: resistor e12 e8 1.2k
  # 入出力の結合
  C1: capacitor b5(-) b12(+) 47uF
  C3: capacitor a10(+) a18(-) 470uF
  # ボード外
  IN:
    type: device
    at: top
    label: 音声入力 50Ω
    pins: [SIG, GND]
  SPK:
    type: device
    at: top
    label: スピーカー 8Ω
    pins: ["+", "-"]
wires:
  # 電源レールの渡し
  - +t2 -- +b2 red
  - -t3 -- -b3 black
  # 入力
  - IN.SIG -- a5 yellow
  - IN.GND -- -t7 black
  # バイアス
  - b16 -- +t16 red
  - d8 -- -t8 black
  - c12 -- f9 orange
  # コレクタ
  - d10 -- f10 blue
  - i5 -- +b5 red
  # エミッタ
  - j15 -- -b15 black
  # 出力
  - SPK.+ -- b18 blue
  - SPK.- -- -t20 black
```

## 回路の読み方

信号は左から右へ流れる。`C1` で直流を切って入力を `Q1` のベースに入れ、
`R1` / `R2` の分圧でベースを約 1.2V に持ち上げる。`Q1` は反転増幅して
コレクタに出し、`C3` で直流を切ってスピーカーへ渡す。

- **バイアス**: Vb = 5 × 1.2k/(3.9k+1.2k) ≈ 1.18V、Ve ≈ 0.53V、
  Ie = 0.53V / 27Ω ≈ **20mA**。Vc = 5 − 20mA × 100Ω ≈ **3.0V** で、
  Vce ≈ 2.5V。コレクタ損失は約 50mW (2SC1815 の Pc 最大 400mW に対して十分低い)。
- **分圧の電流**は 5V / 5.1k ≈ 1mA で、ベース電流 (hFE=200 で約 0.1mA) の
  10 倍。hFE がばらついてもバイアスが動きにくい。
- **利得**: re = 26mV / 20mA ≈ 1.3Ω なので、無負荷なら Rc/re ≈ 75 倍 (37dB)。
  8Ω のスピーカーをつなぐと負荷は Rc∥8Ω ≈ 7.4Ω に落ちるので **約 5.6 倍 (15dB)**。
- **入力インピーダンス**は R1∥R2∥(hfe×re) ≈ 200Ω。50Ω の音源に対しては
  約 0.8 倍に分圧されるが、実験には支障ない。

## 挿すときの注意

- **2SC1815 の足の並び**は品種ごとに違う。図はどの穴が B / C / E かだけを示している。
  2SC1815 は平らな面を見て左から **E・C・B** なので、図のとおり左から B・C・E に
  挿すには**平らな面を奥 (a 行側) に向ける**。
- **電解コンデンサ** (`C1` `C2` `C3`) は帯のある側がマイナス。図でも白い帯を
  マイナス側に描いている。逆に挿すと壊れる。
- `Re` は j11 から下の青レール (GND) へ、縦に挿す。

## 動かしてみると

- スピーカーから出る音は**小さい**。この段が流せるのは静止電流の 20mA までで、
  8Ω に取り出せるのは 1mW 程度。静かな部屋なら十分聞こえるが、実用の音量には
  エミッタフォロワや専用のパワー段を足す必要がある。
- **低音は出ない**。エミッタのバイパス `C2` (470µF) と re ≈ 1.3Ω で決まる折れ点が
  約 260Hz にあるため。小型スピーカー自体も低音を再生しないので実害は小さい。
  気になるなら `C2` を大きくするか、`Re` を 2 本に分けて片方だけバイパスする。
- 入力を上げすぎると波形の頭が潰れる。まず数十 mV から始める。
