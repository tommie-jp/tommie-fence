# スイッチと可変抵抗

押しボタン (タクトスイッチ)・半固定抵抗・スライドスイッチの書き方。

## タクトスイッチで LED を点ける

```breadboard
board: half
parts:
  SW1: button @ e5
  R1: resistor j5 j10 330
  D1: led i12(A) i14(K) red
wires:
  - +t5 -- a5 red
  - j10 -- i12 orange
  - i14 -- -b14 black
```

`button @ e5` は溝をまたいで 4 本足を挿す。占める穴は `e5` `e7` `f5` `f7` で、
足の名前は溝の手前側が `1a` `1b`、向こう側が `2a` `2b`。

**同じ側の 2 本は、押していなくても中でつながっている。** 図の中の細い線がそれで、
ネットリストにもそのまま出る。ここを知らずに `e5` と `e7` を回路の両端に使うと、
スイッチを押す前から短絡している。

```text
+t : SW1.1a, SW1.1b
N1 : SW1.2a, SW1.2b, R1.1
N2 : R1.2, D1.A
-b : D1.K
```

押すと `+t` と `N1` がつながって LED が点く。

## 半固定抵抗とスライドスイッチ

```breadboard
board: half
parts:
  SW2: slide-switch e3(1) e4(C) e5(2)
  VR1: potentiometer e8(1) e9(W) e10(3) 10k
  R1: resistor c13 c16 330
  D1: led c20(A) c22(K) green
wires:
  - +t3 -- a3 red
  - b4 -- b8 orange
  - b9 -- b13 yellow
  - b16 -- b20 green
  - b22 -- -t22 black
```

- どちらも足の穴を並べて書く (3 本足なので `transistor` と同じ書き方)。
- 足の名前は `a9(W)` のように穴に付ける。付けなければ左から `1` `2` `3`。
- **つまみの位置と倒れている向きは図では示さない。** どちらに倒して使うかは
  図からは決まらないので、片側に寄せて描くと嘘になる。本文に書くこと。
- 本体は挿した行とその隣を覆う。3 本足の部品は**溝寄りの行 (`e` / `f`) に挿す**と
  足の名前が板の印字とぶつからず、配線も外側の空いた行 (`a` `b`) から取れる。
