# 1 石中波ラジオ (高周波増幅 + 検波、2SC1815, 3V)

バーアンテナとポリバリコンで同調し、**検波の前にトランジスタ 1 石で高周波を増幅**して
から 1N60 で検波、クリスタルイヤホンで聞く。ゲルマラジオに 1 石足しただけの回路だが、
増幅を検波の前に置くところが「1 石低周波増幅」の定番と違う。

```breadboard
# 電源: 上下の赤レール = +3V (単3 2 本)、青レール = GND (右端で上下を渡している)
board: half
parts:
  # 同調 → ベース (アンテナの 2 次巻線から結合)
  C1: capacitor/ceramic b6 b11 0.01u
  # 高周波増幅 (コレクタ帰還バイアス)
  Q1: transistor h11(B) h12(C) h13(E) 2SC1815
  Rb: resistor d11 d16 180k
  Rc: resistor c16 c21 1.5k
  C4: capacitor/ceramic a21 a25 0.1u
  # 検波 → イヤホン
  D1: diode i12(A) i17(K) 1N60
  C3: capacitor/ceramic g17 g22 0.001u
  R3: resistor j17 j22 100k
  # ボード外
  ANT:
    type: device
    at: top
    label: バーアンテナ 330uH
    pins: [1a, 1b, 2a, 2b]
  VC:
    type: device
    at: top
    label: ポリバリコン 260pF
    pins: [A, E]
  EAR:
    type: device
    at: top
    label: クリスタルイヤホン
    pins: ["1", "2"]
  BAT:
    type: device
    at: bottom
    label: 電池 3V (単3 2 本)
    pins: ["+", "-"]
wires:
  # 電源レールの渡しと電池
  - +t29 -- +b29 red
  - -t28 -- -b28 black
  - BAT.+ -- +b6 red
  - BAT.- -- -b8 black
  # 同調回路 (1 次巻線とポリバリコンを並列に)
  - ANT.1a -- a2 green
  - VC.A -- b2 green
  - ANT.1b -- -t4 black
  - VC.E -- -t9 black
  # 2 次巻線 → C1 → ベース
  - ANT.2a -- a6 yellow
  - ANT.2b -- -t8 black
  - e11 -- f11 orange
  # コレクタと電源
  - e16 -- g12 blue
  - b21 -- +t21 red
  - b25 -- -t25 black
  - j13 -- -b13 black
  # 検波出力 → イヤホン
  - EAR.1 -- f17 blue
  - EAR.2 -- -t23 black
  - h22 -- -b22 black
```

## 回路の読み方

左から右へ、**同調 → 高周波増幅 → 検波 → イヤホン**と並んでいる。

- **同調**: バーアンテナの 1 次巻線 (約 330µH) とポリバリコン (20〜260pF) の並列共振。
  f = 1/(2π√LC) で **約 530kHz〜1.6MHz**、中波帯 (531〜1602kHz) をほぼ覆う。
  つまみを回すと共振周波数が動き、その局だけが大きな電圧になる。
- **結合**: 2 次巻線 (数ターン) から `C1` を通してベースへ。共振回路の
  インピーダンスは数百 kΩ と高く、ベースの入力は 5kΩ ほどしかないので、
  直接つなぐと同調が鈍る。巻線比で落としてから渡すのはそのため。
- **高周波増幅**: `Rb` (180k) をコレクタからベースへ戻す**コレクタ帰還バイアス**。
  Vc が上がるとベース電流が増えて Vc を押し戻すので、hFE が 100〜300 に散っても
  Vc は 1.3〜1.9V、Ic は 0.7〜1.1mA に収まる。抵抗 1 本でこの安定度が出る。
  Ic ≈ 1mA なら gm = 38mS、負荷は Rc と検波回路の並列で約 0.9kΩ、
  電圧利得は **約 30 倍 (30dB)**。2SC1815 の fT は 80MHz なので 1MHz では余裕がある。
- **検波**: `D1` はコレクタに直結する。`Rc` → コレクタ → `D1` → `R3` → GND の
  直流の通り道ができるので、**ダイオードにはあらかじめ約 13µA が流れている**。
  ゲルマニウムの立ち上がりに乗せておくぶん、弱い信号でも検波がかかる。
  `C3` で高周波を落とし、残った音声をクリスタルイヤホンが鳴らす。

## 挿すときの注意

- **バーアンテナの巻線を間違えない**。太いほうの巻線 (ターン数が多い) が 1 次で、
  ポリバリコンと並列にする。細い数ターンが 2 次で、`C1` へ渡す。
  テスターで抵抗を測ると、大きいほうが 1 次。
- **ポリバリコンは 2 連が手に入りやすい**。AM 用 (容量の大きいほう) の片側だけを使い、
  端子 `A` を同調回路へ、`E` (アース) を GND へ落とす。使わない側は開放でよい。
- **`D1` はゲルマニウム**。1N60 や 1N34A を使う。シリコンの 1N4148 に替えると
  立ち上がりが 0.6V あるので、この振幅ではほとんど鳴らない。
- **イヤホンはクリスタル (圧電) のもの**。数十 kΩ の高インピーダンスで受ける前提の
  回路なので、8Ω や 32Ω のイヤホンをつないでも音にならない。
- `C4` (0.1µF) は `Q1` のすぐそばに置く。ここが抜けると `Rc` の上端が高周波的に
  浮いて、利得が落ちるか発振する。

## 動かしてみると

- **鳴るのは近くの強い局だけ**。高周波増幅を 1 段挟んでも、検波が始まるだけの振幅を
  作れるかどうかが境目になる。都市部の地元局なら十分聞こえるが、遠距離は無理。
  バーアンテナの向きを変えると音量が大きく変わるので、まず向きを合わせる。
- **隣の局が混じることがある**。バーアンテナ単体の Q は 150 ほどあるが、
  2 次巻線越しにベースがぶら下がるぶん実効 Q は 70 前後に落ちる。
  帯域にすると 14kHz で、日本の中波の 9kHz 間隔より広い。
- **発振したら**、「ピー」という音や、同調点で急に音量が跳ねる挙動で分かる。
  出力側の配線がアンテナに近すぎるのが原因なので、まずバーアンテナを `Q1` から離し、
  `C4` を確実に効かせる。それでも止まらないときは**エミッタと GND の間に
  10〜47Ω を 1 本**入れる。gm·Re のぶん利得が下がって落ち着く。
  ここで `Rc` を下げても効かない。コレクタ帰還バイアスは Ic·Rc をほぼ一定に保つので、
  Rc を半分にすると Ic が倍になり、利得 gm·Rc がほとんど動かないため。
- **電源は 3V が下限に近い**。単3 2 本で済ませたいのでこの値だが、1.5V 1 本にすると
  Ic が 0.4mA まで落ちて利得は半分ほどになる。上げるぶんには Vc が電源のほぼ半分に
  落ち着いたまま電流だけ増えるので動作点は崩れない (そのかわり電池の減りが早い)。
