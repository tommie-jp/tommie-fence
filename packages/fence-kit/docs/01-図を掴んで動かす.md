# 図を掴んで動かす (3 つのフェンスで同じ操作)

`circuit` / `breadboard` / `perfboard` の 3 つのフェンスは、**同じ殻**
(`fence-kit`) で図を掴んで動かす。鍵も手つきも 3 つで同じ。
フェンスごとに違うのは「何が回せるか」「どの欄が書けるか」だけで、
それは各パッケージの文書に書いてある。

**操作の型は KiCad から借りている。** KiCad を使ったことがあれば、
鍵はほぼそのまま効く。

## 2 つの入口

| 開き方 | どうなるか |
| --- | --- |
| タブの頭の一覧から `<フェンス> Editor` (`circuit Editor` など) | `.md` のタブそのものが図のエディタになる |
| `<フェンス> Fence: 図を掴んで動かす (マップ)` | エディタの横にマップを開く |

一覧は `.md` を開いたタブの頭 (`Text Editor ▾`) にあり、`Markdown Preview` と
並ぶ。**既定の開き方は変わらない。** いつもマップで開きたければ、一覧の
「Set Default for '*.md'」で選ぶ。

## 画面の配置

KiCad と同じ置き方。上に道具の帯、**右に道具の列**、**左に属性**、**下に状態行**。

```text
+------------------------------------------------------------------+
| ↶ ↷ | − ＋ ⤢ | フェンス ▾                                        |
+----------+------------------------------------------+------------+
| 属性     |                                          | ↖ 選ぶ Esc |
| 名前 [ ] |                                          | ▣ 部品 A   |
| 種類 [ ] |            図 (十字カーソル)             | ─ 配線 W   |
| 値   [ ] |                                          | ✥ 動かす M |
| ラベル[ ]|                                          | ⤡ 引きずる G|
|          |                                          | ↻ 回す R   |
|          |                                          | ⇔ 反転 X   |
|          |                                          | ✕ 消す Del |
+----------+------------------------------------------+------------+
| 読めなかった行とお知らせ (折り畳める)                            |
+------------------------------------------------------------------+
| R1: M 動かす / G 引きずる / R 回す / X 反転 …   | c5   | 150 %    |
+------------------------------------------------------------------+
```

- **右の列は鍵と同じ一覧。** 押すと同じ鍵を押したことになる
  (カーソルを部品に置いたまま押せば、その部品に効く。`Ctrl` の要る鍵も押せる)。
  **右クリックでも同じ一覧が出る** — 押した所のものに効く
- **下の状態行**は「いま何ができるか」。カーソルの下の穴とズームも出る
- **属性**は部品を選ぶと欄になる。何も選んでいなければ短いヒント

## 5 つの型

1. **カーソルの下が対象。** 何も選んでいなければ、ホバーしている物に鍵が効く。
   先にクリックしなくてよい。クリックは「選ぶ」で、選んでいればそちらが勝つ
   (同じ部品に続けて鍵を効かせるとき用)
2. **持ち上げて、置く所で 1 クリック。** 置く・動かす・引きずるは全部
   「ゴーストがカーソルに付いてくる → クリックで確定」。押し続けなくてよい。
   ドラッグしても同じ結果になる。**クリックだけでは動かない**
3. **確定前に回せる。** カーソルに付いているあいだ `R` / `X` が効く
   (置く前の部品も、`M` で持ち上げた部品も)
4. **`Esc` は段階的。** 持っている物を捨てる → 道具を「選ぶ」へ戻す → 選択を外す
5. **続けて置く。** 置いたあと同じ種類がまたカーソルに付く。`Esc` で抜ける

## 鍵

| 鍵 | すること |
| --- | --- |
| `A` | 部品を置く (図の上に選ぶ窓が浮かぶ。打って `Enter` で先頭がカーソルに付く) |
| `W` | 配線。始まりの穴をクリック、終わりの穴をクリック (ドラッグでも可) |
| `M` | カーソルの下の部品を持ち上げる。置きたい穴でクリック (接続は変わる) |
| `G` | カーソルの下の節点 (穴) を引きずる。来ているものが丸ごと動き、接続は保たれる |
| `R` / `Shift+R` | 時計回り / 反時計回りに回す (持ち上げているあいだも効く) |
| `X` | 反転 (ゴーストにも効く) |
| `E` / ダブルクリック | 属性の欄へ (名前・種類・値・ラベル) |
| `Delete` / `Backspace` | カーソルの下 (か選んでいる) 部品・配線を消す |
| 矢印 | カーソルの下 (か選んでいる) 部品を 1 穴動かす |
| `Ctrl+D` | 選んでいる部品をもう 1 つ (1 穴ずらして、次の番号で) |
| `Insert` | 直前に置いた種類をもう 1 つ |
| `Esc` | 上の 4 |
| ホイール / 中ボタン (か `Space` + ドラッグ) / `Home` | ズーム / パン / 全体 |
| `Ctrl+Z` / `Ctrl+Y` (`Ctrl+Shift+Z`) | 戻す / やり直す |

## 置く

```text
A → 「tr」と打つ → Enter (transistor が先頭)
  → ゴースト (足が入る穴が光る) がカーソルに付く
  → R で向き、X で足の並び
  → 置きたい穴で 1 クリック
  → 同じ種類がまたカーソルに付く → Esc で抜ける
```

- 名前は**接頭辞ごとに最小の未使用番号**が付く (`D1` が LED なら次のダイオードは `D2`)。
  ID がそのまま図に出る種類 (circuit の `port` / `vcc`) も**既定の名前で置く**
  (窓で止めない)。名前は欄で直す
- **2 本足は既定の間隔で置く** (抵抗 5 穴、LED 1 穴、ほか 3 穴。circuit は 2 升)。
  ドラッグすれば間隔を選べる (押した穴が 1 本目、放した穴が 2 本目)
- 3 本足は押した穴から右へ 2 穴。アンカー 1 つで形が決まる部品 (タクトスイッチ、
  DIP) は押した穴に置く。circuit の多端子は番地 1 つ
- **置けないときはゴーストが赤くなり、状態行に理由が出る** (板の外、レール)。
  押す前に分かる

## 動かす・引きずる

- **部品** (`M` かドラッグ): その 1 つだけが動き、**接続が変わる**。
  最初の穴がアンカーで、形を保ったまま平行移動する
- **節点** (`G`): その穴に来ているものが丸ごと動き、**接続は保たれる**。
  `points:` で名前が付いていれば、直すのは普通その 1 行だけ
- 移動の前後でネットリストを比べ、**離れた接続とつながった接続を状態行に出す**。
  動かす前に止めない

## 配線

`W` → 始まりの穴をクリック → 終わりの穴をクリック (ドラッグでも可)。
`wires:` に 1 行増える。色は書かない (色は後から欄で変える)。
circuit だけ `Shift` を押しながら終わりをクリックすると先に横へ折る (`-|`)。
ほかのフェンスには折れの綴りが無いので、案内にも出ない。

## 同じものを並べる

- **`Ctrl+D`** で選んでいる部品をもう 1 つ。種類はそのまま、名前は次の番号、
  置き場は**1 穴ずらした所** (重ねると、増えたことが図で分からない)
- **`Insert`** で直前に置いた種類をもう 1 つカーソルに付ける
- **矢印**で 1 穴ずつ動かす。置いたあとの微調整はこれがいちばん速い

## 消す・直す

- **消す**: `Delete`。部品を消すと、その部品を指す注釈も一緒に消える
- **欄**: 部品を選ぶと左に出る。`Enter` か欄を離れたときに行へ当たる。
  名前を変えると、その部品を指す配線・注釈も一緒に変わる。
  書けない欄は灰色 (どの欄があるかはフェンスが決める)

## エディタと突き合わせる

マップとエディタは**互いに指し合う**。マップで選ぶと書いてある場所が
エディタで光り、エディタのカーソルを動かすと指しているものがマップで光る。
下の帯には読めなかった行とお知らせが出て、**行を押すとエディタのその行へ飛ぶ**。

## 戻す・やり直す

タブそのものがマップのときは VS Code の `Ctrl+Z` がそのまま効く。
横に開いたパネルのときは、パネルが自分で覚えている (上のボタンか `Ctrl+Z`)。

## 速さのために決めていること

- **ゴーストは接続の変化を数えない。** どの穴を使うかだけを見て捨てるので、
  数えるために図を 2 枚組み直すのは高くつく (穴 1 つで 6ms 対 0.3ms)。
  書き換えそのものは押したときと同じ関数を通るので、見せた物と書かれる物は
  食い違わない
- **同じ本文なら図を組み直さない。** 1 回の書き換えで組み直しが 2 度来る
  (文書が変わった知らせと、操作を捌いたあとの 1 回)。2 度目は同じ図になるので、
  組み直しも送り直しもしない — **送り直すと掴んでいたものが捨てられる**

## 書き換え方

**YAML を組み直さない。** 行の中の穴の綴りだけを差し替え、足すときは 1 行足す。
手書きのコメント・整形・並び順がそのまま残る。フロー形式
(`parts: {R1: …}`) の行は消せない・足せない (行が 1 つのものに対応しない)。
