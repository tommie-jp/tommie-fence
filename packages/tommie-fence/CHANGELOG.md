# 変更履歴

書き方は [Keep a Changelog](https://keepachangelog.com/ja/1.1.0/)、
版のつけ方は [Semantic Versioning](https://semver.org/lang/ja/) に従う。

## [0.3.3] - 2026-09-10

### Changed

- **読めない行があっても、エディタが止まらなくなった。** これまでは YAML が
  1 か所でも転ぶとフェンス全体を捨てていたので、升目が空になり、置く・動かす・
  消す・名前を変えるが**すべて**「フェンスを読めないので…できません」で
  断られていた。直す場所を掴める窓が、直したい瞬間にだけ消えていたことになる。

  これからは**読めた所まで返す**。`yaml` は転んだ行の前後を残すので、読めた
  部品と配線はそのまま図になり、読めなかった行だけが行番号つきで帯に出る。
  置いた行は読めた部品の後ろに入り、**転んだ行は 1 字も触らない** (直すのは
  書いた人)。図 (プレビュー) も同じで、板の 2 つは板を必ず描き、circuit は
  読めた部品が 1 つでもあれば図を出す。

- **`board:` を書く前の perfboard フェンスにも置けるようになった。** 板が
  決まらないと穴の数が決まらないので、これまでは空のフェンスを読めないものと
  して扱っていた。**書き始める前から止まる**ということなので、既定の板
  (`25x15`) で描き、最初に部品か配線を置いたときに `board: 25x15` を書く。

- **本文が 0 行のフェンスにも書き戻せるようになった。** 入れ替える行が無い
  だけで書き足せないわけではないのに、書き戻しが「0 行」を断っていたので、
  空のフェンスに最初の 1 つを置くと「書き換えられませんでした」で終わっていた。

- **`board:` が読めないときに、何の板で描いたかを言うようになった。** 書いた板と
  描いた板が食い違ったまま黙っていると、読み手が図を信じてしまう。`board:` を
  マップで書いて色だけが読めないときは、**書いてある `size:` の板で描く**
  (前は板ごと捨てて既定の板になっていた)。

- **フェンスが 1 本も無い文書でも置けるようになった。** 前は「この文書に …
  フェンスがありません」と言って終わりだったので、新しい `.md` を開いた人は
  まず字でフェンスを書かないと図を掴めなかった。**升目を出し、置いた瞬間に
  文書の終わりへフェンスを 1 本作る**。書いてある字は 1 字も消さない。
  作るのは**タブや頁そのものがマップのとき**だけで、カーソルを追うパネルは
  今までどおり案内を出す (フェンスの外にあるカーソルからは、作る行を決められない)。

- **置いた行が読めないときは断るようになった。** 根がマップでない本文
  (ただの字) へ行を足すと足した行ごと読めなくなるので、「置きました」と言って
  何も増えないことがあった。置いたあとに読み直して、居なければ理由を言う。

- **狭いパネルの字と釦を iOS の寸法にした。** 44px 角は**押せる面**の下限で、
  枠の高さの決めではない。iOS のタブ棒は札 10pt・絵 25pt と小さいまま、
  押せる面が 49pt ある。同じように分けて、縮めるのは字と絵だけにした
  (地の字 15px → 13px、道具の絵 20px → 17px、絵だけの釦 44px → 36px)。
  **押す面は動かしていない** — 道具は 44px のまま、部品や色の一覧の行も
  44px のまま (隣を押すと別の部品が置かれるため)。
  欄の 16px も動かさない (切ると iOS が頁ごと拡大する)。

- **狭いパネルの姿を見直した。** 道具の列を下端に貼り付け (中身がどう動いても
  場所が変わらない)、部品の一覧の行を 44px → 32px に詰め、上の帯の段の間を
  詰めて印を太く濃くした。フェンスの選び手と送りの釦を 1 行に収め、長い題は
  24 字で切る。**高さが足りないとき** (500px 以下) は道具を右へ 2 列で戻し、
  指の案内を畳む。

- **属性の引き出しの印を、部品 (抵抗) の絵にした。** 中身が部品の一覧と属性
  なので、絵がそのまま中身を言う。**言語で描き分けない** — 印は「そこに何が
  あるか」を言うもので、「いま何の言語か」を言うものではない。

- **フェンスの一覧に添える言語名を、その文書に 2 つ以上あるときだけ出す。**
  1 つの言語で書かれた `.md` では、毎行の `(circuit)` は無駄な字だった。

- **消すと、見出しのコメントも一緒に消える。** 見出していた行 (すぐ下から、
  次の見出しか浅い行まで) が全部消えたときだけ。1 行でも残れば残す。
  `parts:` を全部消すと `# 増幅段` だけが宙に残っていた。部品が連れていく
  配線の見出しも同じ。空行の前のコメントや塊の終わりの添え書きは見出しでは
  ないので残る。消えた行数は帯に出す (「コメント 2 行も一緒に」)。

### Removed

- **板 2 つの「フェンスを読めませんでした」のカードを外した** (`.breadboard-error-card`
  / `.perfboard-error-card` と、その中の `-error-title`)。板は必ず描けるように
  なったので、この形は出なくなった。読めなかった行は図の下の帯
  (`.breadboard-errors` / `.perfboard-errors`) に出る。circuit のカードは残る
  (部品が 1 つも読めないと図が組めないため)。

### Fixed

- **板 2 つで、フロー形式に足せないときの断りの尻尾が消す側の文面だった。**
  「行ごと足せません。**手で消します**」と出ていた。足せないときの直し方は
  手で**書く**ほう。消す側の文面から綴りを差し替えて作っていたのが原因で、
  足せない側の文面を別に持つようにした。

- **狭いパネルで、下の道具の列が見切れていた。** 道具を下端の横並びにすると
  図の高さが主軸になるが、図に `min-height` を指定していなかったので、
  flex の既定 (`auto` = 中身より小さくしない) が効いて図が縮まず、
  道具・帯・状態欄を枠の外へ押し出していた。枠は `overflow: hidden` なので、
  押し出された分は**スクロールもできずに消える**。iPhone SE の縦
  (375x667) で 36px 分が消えていた。

- **iOS で、図を触ると本文の選択や共有の吹き出しが割り込んでいた。**
  長押しに iOS の「コピー | 検索」が重なり、2 本指の操作が頁の拡大に
  取られていた。図の上では選択と吹き出しを止め、拡大はマップが受け持つ。

- **1 つの `.md` に 2 つの言語が混ざっていると、一覧から選べなかった。**
  フェンスの一覧は 3 つの言語を混ぜて行順に並べるのに、選んだ行は**いまの
  言語だけ**で引いていたので、別の言語の行を選ぶと「フェンスがありません」と
  言っていた。言語をまたいで探す。

- **掴んで動かすとき、図の中に元の字 (`notes: source`) が出ていた。**
  あれは公開する図に「元の字」を添えるためのもので、editor では字は隣の
  エディタに出ている。二重になるうえ、**板より高い帯が付いて図そのものが
  小さくなる** (実測で板が枠の 1/3 ほどになっていた)。
  **貼る図は 1 バイトも変えない** — プレビューと `.svg` は今までどおり。

- **面のどこでも、ブラウザの右クリックの一覧を出さないようにした。**
  こちらの一覧を開いた後、その一覧の上で右クリックすると素通りしていた。
  欄 (`input` / `textarea` / `select`) では残す — 貼り付けに要る。
  (VS Code の webview には元から無いので、拡張では見た目が変わらない。)

- **まとめて操作すると、閉じ記号の前に空行が 1 つ増えていた。** 範囲削除や
  まとめて動かす・複製するときは、剥がした本文をそのまま書き戻していたので、
  本文の末尾の改行のぶん 1 行多く書いていた。**箇条書きの中のフェンスでは
  字下げまで消えていた** (フェンスが箇条書きから外れる)。変わっていない行は
  文書の行をそのまま使い、変わった行だけに開き記号の字下げを付ける。

- **中身を全部消したフェンスで、戻すことも置くこともできなくなっていた。**
  本文が 0 行になり、書き戻す範囲が無くなっていた。空の 1 行を残す。
  (VS Code は範囲の中身を空にするだけなので元から 1 行残り、拡張では
  起きていない。行ごと抜く宿主 — playground — で起きていた。)

- **分岐点で、光る配線と引き直される配線が食い違っていた。** 2 本が重なる所で、
  ホバーと選択は太い線の当たり判定 (別の配線のものかもしれない) を先に採り、
  引きずると端の的の配線の端が動いていた。端の的を先に採る — 端は線より上に
  描いてあるので、図の重なりとも揃う。

- **題を書いていない図が 2 つ以上ある文書で、直すと図が 1 本目へ飛んでいた。**
  頁は字が変わるたびに「いまのフェンス」を**種類と題**で探し直していたので、
  題が無い図はどれも見分けが付かず、2 本目を直すたびに 1 本目が当たっていた。
  **1 本目が読めないフェンスなら図が白くなり**、置いた部品が消えたように見える。
  行で追う (変わった所より上は同じ行、下はずれた行) 。行で当たらないときだけ
  今までどおり題で探す。(頁だけの話。VS Code はカーソルが正で、殻が追う側。)

- **読めなかった行の名前を、次の部品の名前に選んでいた** (circuit / perfboard)。
  種類の綴りを間違えた行 (`R1: resistr a1 a3`) の部品は数に入らないので、
  `R1` が空いていることになり、同じ名前の行を足していた。帯には「二重に
  定義されています」「部品の名前が重なっています」が出て、置いた部品は図に
  出ない。**`parts:` の下に字として書かれている名前も使用中**として数える
  (3 つのフェンスで同じ手。perfboard は機器の名前もこれで数に入る)。

- **`parts:` の最後が入れ子で書いた部品 (機器など) だと、置いた途端に図が
  消えていた。** 新しい行を最後の部品の**頭の行**の次に足していたので、
  `BAT:` と `type: device` の間に入り、中身が新しい行の続きに読まれて
  フェンス全体が読めなくなっていた (breadboard の例 `09-am-radio.md` で
  抵抗を置くと起きた。複製も同じ)。ブロックの終わりの後ろに足す。
  板に挿す部品は板に挿す部品の並びの末尾に置き、機器の見出し
  (`# ボード外`) の下へは入れない。

### Added

- **節点を引きずる (`G`) ときも、配線の影を出す。** そこへ来ている配線を薄くし、
  動かないほうの端から行き先へ破線を引く。置けない所では赤。今までは行き先の
  穴が光るだけで、来ている線がどう引き直されるかが見えなかった。

- **配線の端に載ると、掴む端を輪で示す。** 状態欄も「配線の端: ドラッグで
  引き直す」と言う。分岐点でどちらの端を掴むかが、押す前に分かる。

- **`SessionHost.onBind`** — 掴むフェンスが変わったことを宿主に伝える口。
  **同じ文書を殻の外にも映している宿主**が、どのフェンスを見せるかを揃える
  ために要る。VS Code は使わない (カーソルが正で、殻が追う側)。

- **`Outgoing` の `notice`** — 宿主からのお知らせを帯 (読めなかった行と
  お知らせ) に足す口。殻の外で起きたことを言う先が要る宿主のためのもの。

## [0.3.2] - 2026-09-07

### Fixed

- **図の上に浮かぶものが、図と一緒に流れていた。** 右クリックの一覧・囲みの帯・
  部品を選ぶ窓を、中身ごとスクロールする箱の中に絶対配置していたので、
  スクロールしたぶんだけ押した所からずれていた。深くスクロールしていると
  画面の外へ出て「出ない」ように見える (実機で breadboard で踏んだ)。

- **配線の端を掴んでも、端として扱われないことがあった。** 掴むための太い線は
  端が四角いので線の先端ちょうどには載っておらず、そこを押すと節点の引きずりに
  落ちていた。同じ配線でも押した端によって結果が変わり、引き直しの影が出たり
  出なかったりする。端の丸に載っていれば、いつでもその配線の端として掴む。

- **まとめて消すと、消したはずのものが残ることがあった。** 注釈は行番号、同じ
  名前の記号は書いた順で指すので、1 つ消すたびに残りの指し先がずれる。部品は
  足を指す配線も連れていくため、順番だけでは足りない。下の行から消し、行で指す
  ものは当てる直前に数え直す。**選んでいない配線を消してしまう**場合もあった。

- **カーソルの下の穴が、印で隠れていた。** 触れている穴を升いっぱいに塗って
  いたので、穴そのものが見えなくなっていた。升より小さい輪にして中を空ける。

### Added

- **狭い画面ではマップを畳むようになった。** 720px より狭いとき、属性パネル
  (属性と部品の一覧) は上の帯のボタンで開閉する引き出しになり、道具の列は
  下端の横並びに移って、図が幅いっぱいに出る。

- **指で図を動かせるようになった。** 1 本指は今までどおり (選ぶ・囲む・動かす)、
  2 本指で移動、開いたり閉じたりで拡大・縮小、長押しで右メニュー。

### Changed

- **部品の一覧を属性パネルに据えた。** 図に重なる窓ではなく左に出しっぱなしに
  なり、窓の絵を押したときだけ今までの浮かぶ窓に移る。よく使う部品の絵と
  配線の色見本は升目に並べ、段ごとに位置がずれないようにした。

## [0.3.0] - 2026-09-07

### Fixed

- **マウスの追従が答えを待っていた。** 試し当ての答えを「カーソルの真下では
  ない」と捨てていたので、影は往復の数だけしか動かなかった (実機で「部品を
  移動中の反応が悪い」)。訊いた場所を覚えて、進んだ分は webview が図の上で
  ずらす — 往復を待たずに付いてくる。

- **右クリックの一覧が効かなかった。** 一覧は図に重ねて出しているのに殻扱いに
  なっておらず、項目へカーソルを下ろす途中で対象が外れ、押した瞬間に選択も
  外れていた。

- **ホバーの印が板の 2 つで出ていなかった。** 実物の姿には塗り替える線が無く、
  縁取りを変える手が効いていなかった。姿のまわりに影を出す。

- **置けない向きにすると影が消えていた。** 置ける穴を足場に姿を切り出して、
  指した穴へずらして赤で出す。

- **板の外の機器を動かせなかった。** 指せる穴が無いので影が出ず、掴んでも
  何も起きないように見えていた。掴んだ所からの差で動かす。

- **配線の端を引き直している間、影が出ていなかった。** 動かさないほうの端から
  カーソルまで線を引き、引き直している線は薄くする。

- **`.vsix` の README の図とリンクが黙って 404 になることがあった。** 基準 URL を
  作る所が落ちても止まらず、空のまま詰めていた。

### Added

- **配線の色を固定のパレットから選べるようになった** (breadboard / perfboard)。
  選んだ色が次に引く 1 本に乗り、配線を選んでいればその 1 本にも効く。
  ドロップダウンと違って**開かずに色が見える**。

- **領域選択と Shift クリックで配線も選べるようになった。** 消せるのは部品と
  配線の 2 つなのに、囲みで拾えるのは部品だけだった。

### Changed

- **試し当ては 1 つずつ送る。** カーソルが動くたびに拡張へ訊いていたので、
  circuit の 1/10 升では秒 60 往復になっていた。答えが返るまで次を送らず、
  最新の 1 つだけ覚える — 往復の数が「マウスの速さ」ではなく「答えの速さ」で
  決まる。フェンスは同じ本文を 2 度パースしない。

## [0.2.0] - 2026-09-07

### Added

- **配線の端だけを掴んで引き直せるようになった。** 線の上を掴むと今までどおり
  配線ぜんぶが動くが、**端の丸を掴むとその端だけ**が動く (実機で「配線の先端を
  選択して、その先端だけ移動できるようにする」)。引き直しは書いた行の
  つなぎ先の綴りを 1 つ書き換えるだけなので、色も注記もそのまま残る。
  **3 つのフェンスとも**同じように効く。

- **右クリックの一覧に「テキストコピー」が付いた** (`C`)。カーソルの下の
  `text` の注釈の言葉をクリップボードへ写す。図に書いた言葉を打ち直さずに
  使えるようにするためのもので、**3 つのフェンスとも**同じように効く。
  写せる字を持たない相手 (部品・配線・印) では、そう言って何もしない。

- **フェンスの一覧に「最初へ」「最後へ」が付いた。** 並びも印もメディア
  プレーヤーと同じ (`|◀` `◀` `▶` `▶|`)。前後の `‹` `›` は三角にして、
  ボタンも押しやすい大きさに広げた。

### Changed

- **ドラッグで動かすときに影がずれなくなった。** 部品は書かれた 1 つ目の穴
  (アンカー) を基準に動くので、胴の途中を掴むとその差だけ跳んでいた。
  **掴んだ升を一緒に送って差を引く** ようにしたので、影も落とし先も掴んだ場所の
  ままになる (3 つのフェンス共通)。

- **升目の刻みが既定で 1/10 升になった** (circuit)。`Ctrl` を押している間だけ
  細かかったのを入れ替え、**`Shift` を押している間だけ升ちょうど**に吸い付く
  ようにした。矢印も同じで、素の矢印が 1/10 升、`Shift` + 矢印が 1 穴。
  `Ctrl` + クリックと `Ctrl` + 矢印は無くなった (`Ctrl+D` と `Ctrl+Z` は今まで
  どおり)。配線を引いている間の `Shift` は、升ちょうどと「先に横へ折る」を
  兼ねる。

- **「エディターで開く」の名前を短くした。** 拡張の表示名を `tommie-fence`、
  editor の表示名を `Fence Editor` にして、メニューには
  `Fence Editor - tommie-fence` と並ぶようにした
  (`Fence Editor (図を掴んで動かす) - tommie Fence` は長すぎた)。
  コマンドの分類も `tommie-fence` に揃えた。

- **フェンスの一覧が「行番号: 題」になった** (`185: 図17 コネクタとレギュレータ`)。
  行番号は 3 桁に揃える (`001` `012`) — 桁数が違うと題の頭が縦にずれる。

### Fixed

- **コアを直したのに `.vsix` が作り直されないことがあった。** 束ねる相手
  (breadboard / circuit / perfboard) のソースを入力に数えていなかったので、
  描画を直しても**前の図のまま**の拡張が入ったまま残っていた。数えるのは
  `fence-kit` だけではなく、`WSDEPS` に挙がる依存すべてにした。

## [0.1.0] - 2026-09-05

### Fixed

- **circuit の図が描けなかった** (`Cannot find module './xhr-sync-worker.js'`)。
  TeX エンジン (node-tikzjax) を束ねてしまっていた。WASM もフォントも
  `__dirname` からの相対で読むので、束ねると `dist/` の隣を探しに行く。
  束ねずに同梱する形へ戻した。

### Added

- **3 つのフェンスを 1 つの拡張にした** (`circuit` / `breadboard` /
  `perfboard`)。「エディターで開く」に 3 つ並んでいたのが 1 つになり、
  選び間違いという状態が無くなる。中身は入口だけで、図を描くのは今までどおり
  3 つのコア (52 の docs/19)。

- **掴んで動かす editor が言語をまたぐ。** 1 つの `.md` に circuit と perfboard が
  並んでいても、いまのフェンスの言語で引く。一覧には言語が添う。
  **パレットと候補の一覧も入れ替わる** — 升目と一緒に送り直し、webview が
  受けて差し替える。

- **命令は 1 つ** (`tommie-fence.openMap`)。**畳む前の id もそのまま効く**
  (`circuit-fence.openMap` など) ので、書いてあるキー割り当ては直さなくてよい。

### 入れ方

**畳む前の 3 つを先に消す。** 残っていると文法もプレビューも二重に登録され、
図が 2 つ出る。`make install` は消してから入れるので、そちらを使えば順番を
間違えようがない。手で入れるときは:

```bash
code --uninstall-extension tommie.circuit-fence
code --uninstall-extension tommie.breadboard-fence
code --uninstall-extension tommie.perfboard-fence
code --install-extension tommie-fence-0.1.0.vsix
```
