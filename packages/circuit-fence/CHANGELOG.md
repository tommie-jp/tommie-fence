## [Unreleased]

### Added

- **よく書く種類を略記でも書けるようにした** (`r` = `resistor`、`gnd` = `ground`、
  `ac` = `sine` など 20 個)。読んだ直後に正式名へ畳むので、図もネットリストも
  エラーの文面も正式名のまま — 略記は**書く手数を減らすためだけ**のもの。
  全部の種類には付けていない。SPICE の素子文字と回路図で通っている略語だけで、
  `q` (npn か pnp か決まらない) のように指すものが 1 つに決まらないものは
  持たせていない。一覧は [docs/syntax.md](docs/syntax.md) の「略記」。

- **注釈の字に大きさ・寄せ・太字を書けるようにした**。大きさは `tiny` /
  `small` / `normal` / `large` / `huge` の 5 段 (極小から極大まで)。寄せは
  `left` / `center` / `right` で、番地を字の左端・真ん中・右端のどれにするかを
  決める。`bold` で太字。`text` と `source` で同じ言葉が使え、**どの順に書いても
  よい**。pt の直接指定は受け付けない — 色と同じで、実機に通した指定だけを
  名前で引く (プレビューの TeX はフォントが無いと例外ではなくプロセスごと落ちる)。
- **`- box 番地 番地 [色]` で図の一角を枠で囲めるようにした**。2 つの番地が枠の
  対角になり、外側に余白を取るので縁の記号やラベルは枠に噛まない。回路の線と
  見分けが付くよう破線で描く。
- **`- arrow 起点 終点 [色]` で指し棒を引けるようにした**。両端とも部品 ID か
  番地。部品を指した端は印 (`circle`) と同じ丸の縁で止まる (真ん中まで伸ばすと
  先端が記号の下に隠れるため)。起点と終点が同じところだと行番号つきで返る。
- グリッドは**点を薄く、行英字と列数字を濃く**描く。点は位置の目安でしかないが、
  英字と数字は読んで番地を数えるものなので、濃さを分けた。色は 1 つのまま
  (`grid-color` の指定はどちらにも効く) で、点だけを薄めて描いている。
- CLI も読めなかった行を **Markdown の行**で返すようにした。フェンスの中の数え方で
  返していたので、プレビューの帯や図に書き出した番号と食い違っていた。
- **`- source 番地 [色]` で、そのフェンスの中身を図に並べられる**。囲みの ```
  も付く。プレビューではフェンスが図に差し替わって書いた YAML が見えなくなるので、
  図と並べて読めるようにしておくためのもの。中身は書き写すのではなく**フェンス
  自身から作る**ので、図を直すと書き出しも動く。行送りは番地の刻みではなく字の
  高さで決まるので、行数が増えても図ほどは伸びない。
- **`notes:` で図に注釈を重ねられる**。`- circle 部品IDか番地 [色]` で丸を描き、
  `- text 番地 [色や大きさ]: 文字` で好きな場所に字を書く。注釈は**回路の一員ではない**
  ので、ネットリストにも分岐の黒丸にも数えない。色は `red` / `blue` / `green` /
  `orange` の 4 つで、明暗どちらのテーマでも読める値にしてある。
- **注釈の字はプレビューでも日本語が出る**。部品の値と違って、フェンスの TeX に
  字を渡さず (渡すとフォントが無くてプロセスごと落ちる)、置き場所だけを描かせて
  描き上がった SVG に差し込むため。書き出す `.tex` は TeX に組ませるので、
  どちらでも同じ字が出る。値では通さない `:` も注釈だけは通す
  (部品の 1 行をそのまま書き写せるように)。
- ` ```circuit ` フェンス (YAML) が Markdown プレビューで回路図になる。
  番地 (`a1` `c3`) で置く場所を書くと、YAML → circuitikz TeX → WASM の TeX
  → SVG の順に描かれる。LaTeX のインストールは要らない。
- 2 端子部品 40 種。抵抗とその仲間 (`resistor` / `resistor-var` /
  `potentiometer` / `photoresistor` / `thermistor` / `thermistor-ntc` /
  `thermistor-ptc` / `varistor`)、
  コンデンサとコイル (`capacitor` / `ecap` / `varicap` / `inductor`)、
  振動子 (`crystal`)、ダイオードとその仲間 (`diode` / `led` / `zener` /
  `schottky` / `photodiode` / `diac` / `thyristor` / `triac`)、
  電源 (`vsource` / `sine` / `square` / `triangle` / `isource` / `battery` /
  `solar`)、切る・光る・鳴る・測るもの (`switch` / `switch-nc` / `button` /
  `button-nc` / `reed` / `fuse` / `lamp` / `speaker` / `mic` / `ammeter` /
  `voltmeter` / `ohmmeter`)。1 端子の記号は `port` / `ground` / `vcc` / `vee`。
  配線は `--` (2 点をまっすぐ結ぶ)。
- 電源レールの `vcc` / `vee` は、**ID がそのまま図に出て、乗っているネットの
  名前にもなる** (端子と同じ)。グラウンドと違って離して描いても自動では
  つながらない (`5V` と `3V3` を同じ節点にしてしまうため)。
- **2 端子部品でも足を持てる**。ポテンショメータのワイパー (`P1.w`)、
  サイリスタとトライアックのゲート (`T1.g`) は、両端を番地で置いたうえで
  3 本目を名前で指す。足を持つかどうかは種類が多端子かどうかではなく、
  足の表を持っているかで決まる。
- ロジックゲート `and` / `or` / `nand` / `nor` / `xor` / `xnor` (入力は `a` `b`
  または `1` `2`) と、入力 1 本の `not` / `buffer` (`in` / `out`)。
- DIP の IC `dip8` / `dip14` / `dip16` / `dip20` / `dip28` / `dip40`。
  足は番号で指し (`U1.1`)、型番は記号の**中**に出る。
  足の本数はパッケージごとに決まっているので、文法に欄を足さず種類の名前に入れた。
- IGBT の `nigbt` / `pigbt` (足は `G` `C` `E`) と、切り替えスイッチの `spdt`
  (`in` / `1` / `2`)。
- `ecap` (電解コンデンサ) は**先に書いた番地が + 側**。曲板の記号で描くので、
  向きは記号そのものに出る (`+` の字は書き足さない)。
- `:` を引用符なしで書いて YAML がマップとして読んでしまったとき、
  「`:` を含む文字は `"…"` で囲みます」を理由に添える (yaml 自身の言い分は
  英語で「Nested mappings are not allowed」とだけなので、直し方が分からない)。
- 種類を書き間違えたとき、近い名前があれば候補を添える
  (`resistr` → 「resistor のことですか?」)。全部を並べるより読みやすい。
- 多端子部品: `npn` / `pnp` / `nmos` / `pmos` / `opamp` / `transformer`。
  1 つの番地に置き、足は `Q1.B` `U1.out` のように名前で指す
  (`Q1.base` のように綴っても同じ)。番地の後ろに書いた型番は記号の下に出る。
  オペアンプは `+up` で ± の上下を選べる。記号の ± は字ではなく線で描く
  (フェンス側のフォントでは字が壊れるか、+ と釣り合わないため)。
- FET は簡易記号 (`nmos` / `pmos`) のほかに、接合型 (`njfet` / `pjfet`)、
  エンハンスメント型 (`nmos-e` / `pmos-e`)、デプレッション型
  (`nmos-d` / `pmos-d`) を書き分けられる。**足の名前はどれも同じ**なので、
  記号だけ後から差し替えられる。
- 配線の折れ。`-|` は先に横、`|-` は先に縦 (TikZ と同じ)。
- 端が別の配線の**途中**に乗っているところ (T 字) はつながっているものとして
  扱い、黒丸を打ってネットリストでも 1 つにまとめる。十字に通り過ぎるだけは
  つながらない。ただし足へ引いた線の上は判定できないので、その旨を伝える。
- **部品も配線も斜めに置ける**。行も列も揃っていない 2 点の間にそのまま引く。
- 端が 3 つ以上集まる交点に**分岐の黒丸**を自動で打つ。
- 同じ場所に置かれた部品を**行番号つきで返す**。図には両方とも描く
  (どちらが間違いかは書いた人にしか分からない)。
- 部品 ID は回路図の慣習どおり組む (`R1` → R の添字 1)。
  値は種類から単位を補う (抵抗の `10k` → 10 kΩ)。
- **ネットリスト**を図の下に畳んで出す。ポートが乗っているネットはポート名、
  グラウンドが乗っていれば `GND`。グラウンド記号は離して描いても同じ節点。
- 読めなかった行を **Markdown の行番号つき**で図の下に出す。読めた部品は描く。
  図がまったく組めなかったときは理由だけのカードを出す。
  1 行の頭には `circuit:` を付ける (`circuit: 7 行目: 種類 resistr は知りません`)。
  プレビューの帯でも CLI の標準エラーでも同じ形なので、
  ほかのツールの出力に混ざっても出どころが分かる。
- CLI (`circuit-fence render`)。1 枚につき `.tex` と `.svg` を書き出す。
  `.tex` は `\documentclass{standalone}` から始まる、LaTeX にそのまま渡せる原稿。
- **`--emit-tex`** — 図を描かず、手元の xelatex 用の `.tex` だけを書き出す。
  フェンスとの違いは**フェンス側の制約が強いる 3 点だけ**。
  - 日本語の値が通る (フェンスはフォントが無く、行番号つきで返す)
  - 単位を siunitx で組む (`100 uF` ではなく `100 µF`)
  - オペアンプが本物の `op amp` になる (フェンスは三角形 + 手描きの ±)

  番地も配線も黒丸も同じなので、プレビューで位置を確かめてから書き出せる。
  日本語のフォントは `\newfontfamily` の 1 行にあり、手元に無ければそこを
  書き換える。値が全部 ASCII のときはその行を書かない。
  値に書ける字は `--emit-tex` で日本語と `µ` `Ω` `°` が増えるだけ
  (`\` `$` `,` `=` はどちらでも書けない)。
  プレビュー用と書き出し用の `.tex` は同じ名前になるので、片方の上に
  もう片方を書こうとしたら、書かずに知らせて止まる。
- フェンス内 YAML の色分け (TextMate injection)。
- **`style:`** で見た目を指定できる。テーマだけなら `style: dark` の 1 行でよい。
  - `grid: on` — **部品を置ける位置**を点で出す。行は左に英字、列は上に数字で、
    ブレッドボードと同じ読み方。`grid-to: e12` で使っていない範囲まで伸ばせる
    (部品を動かす先が見える)。
  - `theme` — `auto` (既定) / `light` / `dark` / `mono`。既定はエディタ追従で、
    明るいテーマでも暗いテーマでも読める。**テーマを変えても図は描き直さない**
    (描き上がった SVG の色を差し替えるだけ)。
  - `ink-color` / `paper-color` / `grid-color` — テーマの色を 1 つずつ上書きする。
  - `pitch` / `standard` / `wire-width` — 1 マスの大きさ、記号の流儀
    (`american` / `european`)、線の太さ。
  - `width` — 出力の横ドット数。図の中身は動かさず外寸だけ変える。

### Notes

- 図は拡張ホスト側で非同期に描き、markdown-it は同期でキャッシュを引く。
  描き終わるとプレビューが描き直される。VS Code のプレビューの CSP は
  `wasm-unsafe-eval` を通さないため、webview の中では WASM を動かせない。
- web 版 (vscode.dev / github.dev) では図を描けない。
  検証・ネットリスト・行番号つきエラーはそのまま使える。
- 日本語の値は、フェンスの TeX にフォントが無いため描けない。行番号つきで返し、
  `--emit-tex` へ誘導する。部品 ID は配線とネットリストで指す名前なので、
  日本語にはできない (英数字と `_` `-` のみ)。
- 記号は 1 つずつ実機に通してから表に載せている。そのままでは使えず、
  素の記号 + 書き足しに置き換えたものが 8 つ。
  - `V` / `sV` / `sqV` / `vsourcetri` (丸い電源) — 落ちないが、circuitikz が
    丸の中身を**縦置き前提で 90 度回して**描く。丸だけの `esource` にして、
    中身 (+ と −、波形) は自分で描いている
  - `eC` (電解コンデンサ) — フォントが無く**プロセスごと落ちる**。
    曲板の `cC` で描く (`ecap`)
  - `op amp` — 記号の中の小さな ± のフォントが無くて落ちる。三角形だけの
    `plain amp` + 線で描いた ± にした
  - `ohmmeter` (抵抗計) — Ω が**太字の数式**で、その太字数式フォントが無くて
    落ちる。丸に字を書くだけの記号に、普通の太さの Ω を渡している
    (普通の太さの Ω は出る。値のラベルの Ω と同じもの)
  - `thRn` / `thRp` (NTC / PTC サーミスタ) — 落ちないが、中の θ が小さすぎて
    字形が無く `#` で出る。素のサーミスタの記号にして、区別は ID の下に
    `NTC` / `PTC` と書く

### Fixed

- **丸い電源 (`vsource` / `sine` / `square` / `triangle`) を横に引くと、記号の
  中身が寝ていた**。直流電源の − が縦棒になり、正弦波・方形波・三角波も縦向きに
  描かれていた。circuitikz が丸の中身を縦置き前提で 90 度回して描いているため
  (手元の LaTeX でも同じ)。丸だけの記号に置き換えて中身は自分で描くようにし、
  **番地の向きによらず一般的な記号の形で出る**ようにした。
  波形は図に対していつも水平で、+ と − だけが配線の向きに沿って並ぶ
  (先に書いた番地が + 側)。書き出す `.tex` も同じ形になる。
- 注釈の色の名前を引くとき、`toString` のように Object.prototype にある名前が
  色として通ってしまっていた。図を描く手前で例外になり、行番号を返せない
  (約束 5) ので、表は自分の持ちものだけを見るようにした。
