# 部品を動かす

図を見ながら部品を別の番地へ移すための操作。**番地で位置を書く**フェンスなので、
「部品を動かす」は行の中の番地の綴りを差し替えるだけで済む。

## 2 つの入口

| コマンド | 何をするか |
| --- | --- |
| `Circuit Fence: 部品を動かす` | 部品を選び、移動先の番地を打つ |
| `Circuit Fence: 部品を動かす (マップ)` | 升目のパネルを横に開き、掴んで置く |

どちらも Markdown のエディタで、**circuit フェンスの中にカーソルを置いてから**
実行する。

## マップで動かす

パネルの升目は、図ではなく**フェンスのモデルから直に描いたもの**。
部品をクリック (または掴んでドラッグ) して、置きたい交点で放す。

升目は手で書き換えてもすぐ追いつく。**図は書き換えのあと数秒で描き直る** —
TeX からの描画は 1 図 1 秒前後かかるので、ドラッグには追従させていない。

図そのものを掴めないのは、描き上がった SVG に番地の手がかりが残らないため。
升目なら位置合わせの問題がそもそも無い。

## 動く量

**最初の番地がアンカー**で、部品は形を保ったまま平行移動する。

```yaml
R1: resistor a1 a3 10k
```

`R1` を `b1` へ動かすと `resistor b1 b3 10k` になる。値やラベルは触らない。

格子の外へ出る移動は断る (a〜z の 26 行、1〜99 列)。
交点の間の番地 (`a_1.5`) を持つ部品は升目に載らないので、マップには出ない
(コマンドからは動かせる)。

## 接続が変わるときは訊く

移動の前後でネットリストを比べ、**離れる接続と生まれる接続を並べて確認**する。
変わらない移動では訊かない — 番地の振り直しで毎回止まると邪魔になる。

同じ番地に 2 つの部品が来るのは、この文法では**接続**。禁止ではなく
「つながる」というお知らせとして出る。

## 書き換え方

**YAML を組み直さない。** 行の中の番地の綴りだけを差し替える。
手書きのコメント・整形・並び順がそのまま残る。

`points:` で名前を付けた節点をそのまま端子に書いていた部品を動かすと、
**その端子は新しい番地のリテラルに変わる** (`points:` の側は触らない)。
名前の節点から離れることは、上の接続の変化に出る。

節点そのものを動かす操作 (`points:` の 1 行を書き換えて、つながっている部品を
連れて動く) はまだ無い。
