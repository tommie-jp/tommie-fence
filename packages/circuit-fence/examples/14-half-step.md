# 交点の間に置く

交点と交点の間に置きたいときは、番地 `x,y` (列,行) を**小数**で書く
(`1.5,1` は列が 1 と 2 の間、`1,1.5` は行が 1 と 2 の間)。小数は 2 桁 (1/100) まで。

番地は数字で始まって `,` を含むので、`.` があってもピン (`U1.5` は DIP の 5 番ピン) とは
字の形で分かれる。

```circuit
title: 図01 交点の間に節点を置く
parts:
  IN:  port 1,1
  R1:  resistor 1,1 2.5,1 10k
  C1:  capacitor 2.5,1 2.5,3 100n
  G1:  ground 2.5,3
  OUT: port 4,1
wires:
  - 2.5,1 -- 4,1
notes:
  - source 5,1 blue
style:
  grid: on
```

![図01 交点の間に節点を置く](out/14-half-step-1.png)

抵抗の右端を `2,1` と `3,1` の間に置いた。**他の番地を振り直さずに**節点を
ずらせるのが、間を書ける理由。グリッドの点は**交点の上にだけ**打つので、
間に置いた部品は点と点の間に乗る。

```circuit
title: 図02 並んだ枝の間に 1 本足す
parts:
  IN:  port 1,1
  R1:  resistor 1,1 5,1 1k
  R2:  resistor 1,2 5,2 2k
  R3:  resistor 1,2.5 5,2.5 3k
  R4:  resistor 1,3 5,3 4.7k
  OUT: port 5,1
wires:
  - 1,1 -- 1,2 -- 1,3
  - 5,1 -- 5,2 -- 5,3
notes:
  - source 6,1 blue
style:
  grid: on
  pitch: 3
```

![図02 並んだ枝の間に 1 本足す](out/14-half-step-2.png)

`R3` だけが行 2 と 3 の**間**にいる。後から 1 ピンしたくなっても、
**`R4` から下を振り直さずに済む**のがここでの効き目。左右の縦線の途中に
乗るので、つなぎ方はほかの枝と変わらない (ネットリストでも同じ節点に入る)。

**間隔が詰まると記号も詰まる**。この図が `pitch: 3` を書いているのはそのため —
既定の 2cm のままだと、半マス (1cm) しか離れていない `R2` と `R3` で、
値の字と ID の字が重なる。狭いと感じたら、番地ではなくマスのほうを広げる。

## どちらへずれるか

**x (前の数) の小数が右へ、y (後ろの数) の小数が下へ**動かす。同じ `.5` でも、書く場所で向きが変わる。

```circuit
title: 図03 x は右へ、y は下へ
parts:
  P1: port 1,1
  P2: port 3.5,1
  P3: port 6,1.5
  P4: port 9.5,1.5
notes:
  - text 1,2 blue center: 交点
  - text 3,2 blue center: x を .5 (右へ)
  - text 6,2 blue center: y を .5 (下へ)
  - text 9,2 blue center: 両方 .5
  - source 11,1 blue
style:
  grid: on
  pitch: 3
```

![図03 x は右へ、y は下へ](out/14-half-step-3.png)

`1.5,1` は `1,1` の右、`1,1.5` は下、`1.5,1.5` はその両方。小数の並びは
番地そのものと同じ (列 → 行) なので、覚えるものは増えない。
