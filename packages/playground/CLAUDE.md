# プロジェクト指示 (playground)

3 つのフェンスを**ブラウザだけ**で試す 1 枚の静的ページ。
拡張を入れずに「書くと図が出る」ところまで見せるための入口
(もう 1 つの入口は Codespaces。判断は 52 の docs/15)。

置き場は GitHub Pages。リポジトリ直下の `.github/workflows/pages.yml` が
`dist/` をそのまま上げる。

## ここは拡張ではない

`contributes` を持たないので、`scripts/packages.mjs` は拡張と数えず、
`doBuild.sh` / `make` の `.vsix` の対象から外れる。
`make check` には乗るので、`typecheck` と `test` は通し続ける。

## 約束

1. **3 つのコアを直に呼ぶ。** 描画の決め事はこちらに書かない
   (`fences.ts` が 3 つを 1 つの形に揃えるだけ)。文法も図もあちらが正。
2. **circuit の図は TeX を持ってきて描く。** WASM の TeX
   (node-tikzjax のもの) をブラウザで走らせる。**要るときだけ落とす** —
   資材 8.5 MB は circuit の図を初めて描くときに取りに行き、
   breadboard と perfboard しか見ない人には落とさせない。
   後処理 (`finishSvg`) はコアのものを通すので、描き上がりは拡張と揃う。
3. **マップは iframe を webview の代わりにする。** 拡張では VS Code が
   webview を用意し、拡張ホストと `postMessage` で話す。その形をそのまま
   写したので、**殻 (fence-kit) も文法も 1 行も変えずに動く**。
   頁が肩代わりするのは 3 つ: 送り口 (`acquireVsCodeApi`)、色の変数
   (`--vscode-*`)、そしてカーソル — 頁にカーソルは無いので、
   「いま見せているフェンス」の本文の 1 行目を渡す (`map/host.ts`)。
   **3 つの言語を一度に渡す** ので、別の言語のフェンスへ移っても
   殻の側で乗り換わる (開き直さない)。
4. **例は `.md` のまま配る。** `scripts/examples.mjs` が各パッケージの
   `examples/` から `.md` を `dist/examples/` へ写し、一覧 (`examples.json`)
   を書く。**中身は書き換えない** (直した日に 2 つが食い違わない)。
   フェンスだけを抜き出さないのは、**散文とフェンスが混ざった本物の文書**を
   開くところがデモの本体だから (52 の docs/43)。
5. **決め事は DOM を知らない場所に置く。** テストの対象は `document.ts` /
   `workspace.ts` / `share.ts` / `examples.ts` / `files.ts` / `fences.ts` /
   `demo.ts`。DOM を触る配線は `src/page/` に**役ごとに分け** (52 の docs/49)、
   `main.ts` は「文書に何かが起きたら映す」(`sync`) と開いたときの支度だけ。
   **文書の変化は `page/workspace.ts` の `changed(kind)` を通す** — 各所が
   図・一覧・マップを個別に組み直すと呼び漏らしが出るので、映す側が 1 か所で
   受けて 1 通りに揃える。
6. **外から来た字は境界で確かめる。** URL のハッシュ (`share.ts`) と
   `examples.json` (`examples.ts`) は、読めなければ null か空で返し、
   落とした数を画面に出す。黙って捨てない。
7. **どこにも送らない。** 図もフェンスもブラウザの中だけで動く。
   共有は URL に載せるだけで、預け先を持たない。
   **だから配ったリンクは「こちらが読めなくする」以外では切れない。**
   次の約束はそれを守るためのもの。
8. **共有リンクの読み口は足すだけ。減らさない** (判断は 52 の docs/37)。
   リンクは種類を**平文で**載せ (`#breadboard/…`)、中身も base64 で
   埋め込んである。**綴りを変えると、配ってあるリンクが黙って読めなくなる。**
   - 種類の別名は `kinds.ts` の `ALSO` に足す。**期限を切らない**
     (52 の docs/08 の「別名を落とすコストは見えない黙った壊れ方」と同じ)。
   - 綴り (`#<種類>/<base64url>`) を変えるとき — 圧縮や短縮を入れるとき —
     は、**旧い形も読み続ける**。新しい形は見分けが付く印で始める。
   - 受け口を緩めるのは**リンクの読み口だけ**。画面の状態と `examples.json`
     は自分で作るので `isKind` (正の綴りだけ) のまま。
9. **スマホではアプリになる** (PWA。判断は 52 の docs/35)。ホーム画面から
   開いたときだけ `body.app` を付けて、**編集する所だけ**を出す
   (見出しと「気に入ったら」も畳む。頁として開いた人には、狭い画面でも
   この 2 つを 1 行ずつ残す — 52 の docs/48)。同じ 1 枚で両方をまかなう。
   manifest の道は**相対**で書く (置き場が Pages の `/tommie-fence/` と
   手元の `/` の 2 つあるため)。
10. **絵札は組み立てが焼く。** 約束 2 の「外から持ってこない」と揃える —
   ラスタライザ (sharp は 30 MB の native) を足さず、favicon と同じ図案を
   zlib で PNG に詰める (`scripts/icon.mjs`)。
11. **控え役は先読みしない。** 束ねた塊の名前は中身のハッシュなので、
    先読みの一覧を作ると組み立てと二重管理になる。一度通った道を控えるだけ。
    **控えを先に返してよいのは、名前に中身の指紋が入っているものだけ**
    (`chunk-*.js` / `tex/` / `icon-*.png`)。`app.js` も `style.css` も名前が
    変わらないので、控えを先にすると**直しが 1 回目の表示に出ない**。
    そちらは網が先で、駄目なときだけ控えから返す。
12. **editor から始める** (デモとしての形。判断は 52 の docs/48 — docs/41 の
    「図 → 字」を覆した)。開いた瞬間にマップが出ていて、図を掴めば
    Markdown が書き換わる — **このプロジェクトにしか無い動き**を最初の
    10 秒で見せる。**「GUI で編集」の釦は無い** (マップは開いたら閉じない)。
    字と図は「Markdown」の窓 (約束 22)。
    頁は 見出し → 帯 → マップ → 気に入ったら。
    **既定の例は 3 つとも「図01 LED と抵抗」** — 同じ回路を
    3 通りに描けることが、3 つを 1 つに畳んだ理由だから。
    **わざと壊した例は `?dev` のときだけ**欄に出す。
    一覧の並びは **circuit → breadboard → perfboard** (作る人の順)。
    **最初に開く文書はその先頭にしない** — circuit の図は初回に TeX の資材
    8.5 MB を落とすので、開いた瞬間の 1 枚には向かない (docs/15 の実測)。
    editor から始める今も breadboard のまま — **breadboard のマップは本物の
    描画に掴む層を重ねたもの**で、circuit のマップは editor 用の絵
    (TeX は窓を開くまで落とさない)。最初の 1 枚は本物の図のほうがよい。
13. **「試す」釦は当たるものだけ出す** (`demo.ts`)。`nudge` はちょうど
    1 か所のときだけ書き換え、0 か所・2 か所以上では null を返す。
    **押しても何も起きない釦は「壊れている」と読まれる。**
    釦は例の本文の断片を探すので、**例を直すと黙って死ぬ** — 試験が
    例を fs で読んで当たり続けているか見張っている。
14. **文書は Markdown の全文、フェンスはその中の範囲** (52 の docs/43)。
    テキスト欄 (Markdown の窓の中) には全文を出し、図に出すのは
    「いまのフェンス」1 本。
    **どれが「いま」かはカーソルが決める** — 拡張と同じ決め方で、
    欄のカーソルでも、フェンスの選び手でも、マップの中の一覧でも動く
    (殻の `onBind` で揃える)。**フェンスの本文だけを欄に出して裏で継ぎ戻す
    形にしない** — 書き換えの経路が殻と頁の 2 通りになる。
15. **開く口は 3 つ、書き戻す道は 3 段** (`files.ts` と `page/files.ts`。52 の docs/43 / 45)。
    釦・落とす・`?doc=` のどれも `openDoc` へ来る。
    - **掴み手が取れたら、その場に書く** (File System Access。Chromium の PC)。
      2 回目からは窓を出さずに上書きする。取れなければ**同じ名前で
      ダウンロード** — iOS には picker が無く、これが唯一の「外へ書く」。
      **その場に書けなかったら落とす道へ落ちる** (許しを取り消された等)。
      黙って何も起きないのが一番困る。
    - **掴み手は文書を開き直すたびに落とす** (`openDoc`)。残すと別のファイルを
      上書きする。
    - **改行の形は開いたときのものを保つ** — テキスト欄が値を LF に均すので、
      Windows の `.md` を開いて保存しただけで全行が変更扱いになる。
    - **直したまま閉じさせない** (`beforeunload`)。名前の横に印を出す。
    - **保存先は知れない。** ダウンロードの行き先を頁に教える API は無いので、
      「どこへ入ったか」は**言わない** (当て推量を書くと、外れたときに探す
      場所を間違えさせる)。代わりに**どの道で出したか**を言う。
      掴み手を持てない窓で共有シートが使えるなら、そちらへ出す —
      **知らせられないなら、選ばせる** (52 の docs/45)。
16. **引き出しの印は、いつでも抵抗の実体図** (言語で描き分けない)。
    印は「そこに何があるか」を言うもので、「いま何の言語か」を言うものでは
    ない (それは図が言っている)。言語ごとに別の絵にすると、**印としての
    覚えやすさが消える** (実機で決め直し。52 の docs/46)。
17. **掴んで動かすときは書き出しを出さない** (`edit: true` のとき、
    breadboard と perfboard のコアが `notes: source` を描かない)。あれは
    公開する図に「元の字」を添えるためのもので、editor では字は隣の欄に出て
    いる。二重になるうえ、**板より高い帯が付いて図そのものが小さくなる**。
    `.md` の字は Markdown の窓で見る (約束 22)。
18. **スマホの姿は 2 つの畳み方で決める** (52 の docs/46)。
    - **幅 720px で畳む** (マップと同じ閾値)。頁とマップが別の姿で
      組み合わさる所を作らない。
    - **高さ 500px でも畳む** — 横向きの iPhone は幅 667〜932px で 720 の
      両側にまたがるので、幅で決めると機種で姿が変わる。**足りないのは高さ。**
      頁 (`page/layout.ts` の `NARROW`) と CSS の狭い画面の規則の**両方**に当てる
      (片方だけだと、畳んだ姿なのに字の欄が 13px で、触ると iOS が頁ごと
      拡大する。52 の docs/48)。
    - 畳んだ姿 (`body.full`) の帯は**1 段**: `[≡] 文書名 ● [保存][Markdown][ログ]`。
      **たまにしか押さないもの** (例・開く・QR) は `≡` の板へ。
      **保存は畳まない** — 保存が 2 タップになるのが一番困る
      (頁を閉じると字は消える)。**文書名に幅を残す** — 「何を直して
      いるか」なので、釦の余白と間を詰めて返す。
    - 印は `≡` (ハンバーガー)。マップの引き出しの印は抵抗の絵 (約束 16)
      なので、役が分かれる。
19. **しくじりは残る所に出す** (52 の docs/46)。**ログに赤で**、開いていれば
    マップの帯 (読めなかった行とお知らせ) にも赤で。**畳んだ姿の一言
    (`.said`) には出さない** — 長い断りを入れると 1 行の帯が崩れて釦が
    押しのけられる (実機で踏んだ)。**ログは `···` の中に入れない** —
    しくじりを読む場所なので、いつでも 1 押しで開ける所に置く。
20. **出来事は `say()` を、しくじりは `warn()` を通す** (`page/log.ts`。
    52 の docs/45)。`say()` は帯 (2 秒で消える) と**ログ** (最後の 20 行) の
    両方に、`warn()` はログに赤で 1 行と、マップの帯 (開く前なら頁の帯) に出す
    (約束 19)。別の口を作ると、呼び忘れた出来事だけがログに出ない。マップの帯へ
    出た一言も `onStatus` でログへ落とす。ログは読み込み直すと消える (文書は
    外のファイルなので、そちらを見れば分かる)。
21. **URL は文書の中身ではなく、置き場を指す** (52 の docs/43 / 44)。
    - 頁は `#` に図を書かない。書く側 (`encodeShare`・「リンクをコピー」・
      中身を載せた QR・短縮の表引き) は落とした。**読む側は残す** —
      配ってあるリンク (`#<種類>/<base64url>`) と、それを指している
      s.tommie.jp の転送ページ 109 本を切らないため (約束 8、docs/37)。
    - アドレス欄は開いている文書に合わせる (`?doc=…`)。**読み込み直しても
      同じものが出る。**
    - **QR も同じリンクを出す** (`linkTo` が 1 か所で決める。2 通りに数えると、
      配った QR と手元の URL が食い違う)。**手元のファイルには置き場が無い**
      ので、そのときは頁の URL だけを入れて、渡せないことを窓で言う。
    - `?dev` はアドレス欄には残すが **QR には入れない** (人に渡す字なので)。
22. **Markdown の窓** (`<dialog>`。52 の docs/48)。前の頁の 2 つの欄 —
    文書の全文と、いまのフェンスの図・試す・TeX・ネットリスト — をそのまま
    入れた。**字だけの窓にしない**: circuit のマップは editor 用の絵で、
    公開する図 (TeX) ではない。本当の図を見る場所を頁に残す。
    - **欄は文書の正のまま。** 閉じた窓の中でも値は生きているので、
      打鍵 → マップの組み直しの道は 1 行も変わらない。
    - **図は窓が開いているときだけ描く** (`paintFence`)。閉じているあいだは
      マップが図の役。circuit の TeX を、窓を開かない人に落とさせない。
    - **開いたら、殻が直前に書き換えた行を選んでおく** (`changedSpan`)。
      窓にすると「掴む → 字が変わる」を同時には見せられないので、その代わり。
      **いまのフェンスの中の所だけ** — 別のフェンスの所を選ぶと、次に欄を
      触った瞬間に図がそちらへ戻る。無ければ、いまのフェンスの 1 行目
      (カーソルが既にその中なら動かさない)。
    - **焦点を移すのは、窓を開いたときの、マウスのある端末だけ**
      (`pointer: fine`)。指の端末で移すとキーボードが出て窓が隠れる。
      窓のフェンスの選び手からは移さない (矢印で送る人が 1 つ目で止まる)。
      最初の焦点は「閉じる」(`autofocus`) — 無いと窓は最初の欄に焦点を
      置くことがある。
    - **窓が開いているあいだは指で広げられる** (畳んだ姿の拡大止めを外す)。
      窓の図は画面の幅に縮めて出すので、込み入った回路は広げないと読めない。
    - 狭い画面 (約束 18 の畳む条件) では画面いっぱい、字が先。広い画面は
      左に字・右に図。閉じる釦は「閉じる」(QR の窓と同じ言葉。Esc でも閉じる)。

## コマンド

リポジトリ直下から:

```bash
npm run check --workspace=playground    # 型チェック + テスト
npm run build --workspace=playground    # dist/ を作る
npx -y serve packages/playground/dist   # 手元で開く (python3 -m http.server でもよい)
```

`npm run watch` は束ねるものだけを見張る。HTML と CSS と例と
TeX の資材は `npm run build` のたびに写す。

TeX の資材 (`dist/tex/`) は **node_modules の node-tikzjax から写す**。
リポジトリには置かない (8.5 MB のバイナリを二重に持たない)。

## 構成

**決め事 (DOM を知らない。テストがある):**

- `src/kinds.ts` — 3 つの種類。依存を持たない小さな島
- `src/fences.ts` — 3 つのコアを 1 つの入口に。**ここだけが 3 つを知っている**
- `src/document.ts` — 文書の数え方 (フェンスの取り出し、題、カーソルの行、
  変わった行の範囲 `changedSpan`)
- `src/workspace.ts` — 頁が持つ文書 1 つの状態。**字は持たない** (欄が正) —
  いまのフェンス・直したか・殻が直前に書き換えた所を数える。窓を開いたとき
  欄のどこを見せるか (`spanToReveal`) もここ
- `src/share.ts` — 配ってあるリンクの**読み** (`#<種類>/<base64url>`)
- `src/examples.ts` — `examples.json` の受け取り (形の確認)、最初に開く例、
  欄に出す名前
- `src/files.ts` — 開く・書き戻す・**どこを指すか** の決め事
  (改行の形、名前、`?doc=` の綴り、`linkTo`)
- `src/qr.ts` — QR の升目 (`qrcode-generator` を束ねる)
- `src/demo.ts` — 「試す」釦の中身
- `src/reveal.ts` — テキスト欄の中の範囲を見える所へ寄せる。**折り返しを
  数えるため写しを作って測る**ので DOM が要る (jsdom で覆う)

**頁の配線 (`src/page/`。DOM を触る。役ごとに 1 つ):**

- `page/els.ts` — `index.html` の要素。無ければ開いた時点で止まる
- `page/workspace.ts` — 文書の実体 (`ws`) と、変化の知らせ (`changed` /
  `onChange`)
- `page/log.ts` — 出来事の口 (`note` / `say` / `warn`)。jsdom で覆う
- `page/paint.ts` — 窓の右側 (図・TeX・ネットリスト)。文書の状態は持たない
  (描きかけの番号だけ持つ)。jsdom で覆う
- `page/labels.ts` — 見出しの一文・文書の名札・出どころ。文書は引数で受ける。
  jsdom で覆う
- `page/dialog.ts` — 釦から開く `<dialog>` の作法 (`aria-expanded`)。jsdom で覆う
- `page/where.ts` — アドレス欄 (`?doc=`) と `?dev`
- `page/layout.ts` — 畳む・板・指の拡大・控え役
- `page/markdown.ts` — Markdown の窓 (開け閉め、字の欄の打鍵、フェンスの選び手、
  どこを見せるか)
- `page/demo.ts` — 「試す」の帯
- `page/examples.ts` — 例の一覧 (取る・並べる・開く)
- `page/files.ts` — 開く口 3 つと書き戻す口 3 段、落として開く
- `page/qr.ts` — QR の窓
- `page/map.ts` — マップ (iframe) を開く。殻からの書き換えと選び直しを受ける
- `src/main.ts` — 組み立て。`sync` (文書に何かが起きたら、`PLAN` の表のとおりに
  映す) と `start`
- `src/map/` — 図を掴んで動かすマップ。`doc.ts` (テキスト欄を Markdown に
  見せる) と `host.ts` (殻が求める外の世界) が純関数でテストがあり、
  `webview.ts` は iframe の中で動く。**`import()` で読む**ので別のかたまり
- `src/tex/` — circuit の図を描く一式 (node-tikzjax をブラウザへ移したもの)。
  `tar.ts` だけが純関数でテストがある。残りは fetch / WASM / DOM が要るので
  ブラウザで確かめる。**`import()` で読む**ので別のかたまりになる
- `src/sw.js` — 控え役 (service worker)。**束ねない** — 出所の根に置く
  1 本で、組み立てが版を差し込んで `dist/` へ写す
- `scripts/examples.mjs` — 例を集める (ビルド時)
- `scripts/icon.mjs` — PWA の絵札を焼く (ビルド時)。型は `icon.d.mts`
- `src/index.html` / `src/style.css` — そのまま `dist/` へ写す
- `dist/manifest.webmanifest` — 組み立てが書く (版と絵札の一覧を持つので、
  手で書くと `package.json` と食い違う)
