# graph フェンス 早見表

**1 画面に収めた全形式。** LLM に書かせるときは、これをそのままプロンプトに貼る。
詳しい説明と図は [01-syntax.md](01-syntax.md)。

## かたち

````text
```graph
title: 図01 共振曲線             # 任意。図の左上に載る 1 行
x: 周波数 Hz log 2k..32k        # 名前 単位 [log] [範囲]。範囲の区切りは ..
y: 電流 mA                      # 任意。名前 単位 [log] [範囲]。単位が 2 つ以上なら並び
lines:
  出力 50Ω mA:                  # キーの最後の語が単位 (枠を分ける鍵)
    - 2k 0.38                   # 点列: 1 行 1 点 (x y)。軸の単位は付けても省いてもよい
    - 15.9k 17.6
  式 mA: 20*x/1k                # 式: x の関数 (x は横軸の単位の数)
data: 9-1.csv                   # 任意。.md の隣の CSV → ○ で打つ (線で結ばない)
notes:
  - mark 15.9k                  # 縦の破線と、各線の読み値
  - band 14k 18k: LED が点く     # x の帯
style: dark                     # 任意
```
````

理想 (式・点列) は**実線**、`data:` は**○**。単位が違う線は**縦に積んだ別の枠** (3 つまで) で、x を共有する。
軸の名札は「量/単位」(`周波数/Hz`)、対数なら `(対数)` が付く。

`style:` は 1 語 (`light` `dark` `mono`) か並び (`theme` `width` (120〜4000) `stamp` `debug` (`on` / `off`))。

## 軸 (`x:` `y:`)

```yaml
x: 周波数 Hz log 100..100k    # 対数の横軸
y:
  - 利得 dB -40..0            # 単位ごとに 1 行
  - 位相 deg
```

- 後ろから読む: 最後の語が `a..b` なら範囲、その前が `log` なら対数、その前が**単位**、残りが名前
- **範囲の区切りは `..`** (`2k..32k` `-40..0`)。`2k-32k` は断る。対数は 0 より大きい値から
- 範囲を省くと値から決める。**大きさの量 (mA・V …) は 0 から**、dB と deg は値を包む
- **式だけの図は `x:` に範囲が要る** (どこからどこまで計算するかが決まらない)
- `y:` を省けば単位だけの名札 (`mA`)。量の名前を出すなら `y:` に書く

## 線 (`lines:`)

```yaml
lines:
  利得 dB: 20*log10(1/sqrt(1+(x/1.59k)^2))
  位相 deg: -deg(atan(x/1.59k))
  1N4148 mA: 4.4n * (exp(x / (1.9 * 25.9m)) - 1) * 1000
  出力 ≈0Ω mA:
    - 2k 0.38
    - 15.9k 24.9
```

- キーは「名前 単位」。**単位は必須** (`電流:` は断る)。8 本まで。色は書いた順に 4 色
- 点列は x の順に並べ直す。同じ x が 2 つあれば断る。点は 1 本に 1001 個まで
- 式は**無次元**で、値は線の単位で読む。A で出る式を mA の線に書くなら `* 1000`

## 式

数は接頭辞つきでよい (`1.59k` `25.9m` `4.4n` `10M`)。**`m` と `M` は別** (1/1000 と 10⁶)。`u` は `µ`。

| 書けるもの | |
| --- | --- |
| 値 | 数、`x`、`pi` |
| 演算 | `+` `-` `*` `/` `^` (右結合。`-x^2` は −(x²))、括弧 |
| 関数 | `sqrt` `exp` `ln` `log10` `log2` `sin` `cos` `tan` `atan` `atan2` `abs` `min` `max` `pow` `floor` `ceil` `deg` `rad` |

**掛け算の `*` は省けない** (`2x` は断る)。200 字・32 段まで。

## 注釈 (`notes:`)

```text
notes:
  - mark 1.59k              # 縦の破線。読み値の表に 1 行 (8 本まで)
  - level -3dB              # 横の破線。単位で枠が決まる (枠が 1 つなら単位は省ける)
  - band 14k 18k: 字         # x の帯 (字は任意)
  - text 16k 27mA: f₀        # 点に字 (y は単位つき)
  - peak                    # 全部の線の頂点に印。読み値に出る
  - source                  # フェンスの中身を図の下に書き出す
```

6 つ: `mark` `level` `band` `text` `peak` `source`。番地は軸の値 (x は単位を省ける、y は単位で枠が決まる)。

## 測った値 (`data:`)

```yaml
data: 9-1.csv    # .md と同じ場所の .csv / .txt だけ (/ や .. は書けない)
```

- 1 列目が x、以降が y。区切りは `,` かタブか `;`。`#` の行は読み捨てる
- 見出しの括弧の中が単位 (`周波数 (kHz)`)。**x は軸の単位に直す** (kHz → Hz)。違う単位は断る
- 列は「単位と名前が合う線」→「単位が合う線が 1 本」→「新しい線」の順に当たる
- 読めない・見つからないはお知らせで、図は理想だけで出る

## 読み値 (`graph-fence check`)

```text
読み値 — 理想 (計算)
周波数    利得      位相
1.59 kHz  −3.01 dB  −45.0°
```

**本文の「見るべき値」の表と数で突き合わせる。** 合ってから PNG を 1 度見る。

## 取り違えやすい所

- **画面を見せる題は scope / spectrum / vna、値を集めて描く題は graph**
- 範囲は `..` (vna の掃引の `1M-300M` ではない)
- 単位は軸と線のキーに書き、**凡例と目盛には出さない** (名札の 1 か所)
- 実測は ○ で打ち、線で結ばない。線で結ぶのは理想 (式・点列) だけ
