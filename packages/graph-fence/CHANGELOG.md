# 変更履歴

書き方は [Keep a Changelog](https://keepachangelog.com/ja/1.1.0/)、
版のつけ方は [Semantic Versioning](https://semver.org/lang/ja/) に従う。

## [Unreleased]

## [0.6.0] - 2026-11-12

### Added

- **点の名札。** 点列の点の後ろにコロンと字を書くと (`- 4 3: 最初の 1 台`)、その点に ● を打ち、名札を周りの空いた所へ置く。
  枠の内に収め、線・ほかの名札・ほかの名札つきの点に掛けない (8 方向を近い順に試す)。空きが無ければ重ねて描き、お知らせで言う。
  1 枚に 24 個・24 字まで。名札の無い図は今までと同じ

### Fixed

- 注釈の `text` の字が枠の左右の縁で外へはみ出していた。枠の内へ寄せる

## [0.5.0] - 2026-11-02

### Added

- **想定どおりのお知らせ (`expect:`)。** わざと壊した見本や範囲の外を見せる図で、出るのが正しいお知らせを、
  `- match: 文の一部` と `why: 理由` (必須) の組で承知する。黙らせずにログで `[想定どおり: 理由] …` と言い分け、
  当たらない承知は「当たるお知らせが出ていません (直ったなら消します)」とお知らせで言う。エラーには効かない

## [0.4.1] - 2026-11-02

### Fixed

- `level` の値の字 (`7.60 dB` など) が `mark` の縦の破線に横切られて読めなかった。字に破線が掛かるときは、その線の左へ寄せる (寄せきれなければ従来どおり右端)

## [0.4.0] - 2026-10-18

### Added

- **`lang: en`** — 図の中の固定の字 (読み値の見出し・`peak` の `値`・対数軸の `(対数)`・`data:` の既定の凡例名) を英語で出す。`renderGraph` の `options.lang` でも指せる (先に効く)。既定は `ja` で出力は変わらない

## [0.3.0] - 2026-10-05

### Added

- `data:` のファイル名の後に**凡例の名前**を書ける (`data: 9-1.csv 計算`、20 字まで。空白を含んでよい)。凡例と読み値の見出しに出る。書かなければ今までどおり `実測`。計算で作ったファイルを重ねた図が「実測」と言い切っていた (vna と同じ書き方)

## [0.2.1] - 2026-09-30

### Fixed

- **`style:` の `on` / `off` に `constructor` などの継承された名前が通っていた** — 語を普通のオブジェクトで引いていたので、`stamp: constructor` が真として読まれ刻印が出た。自分の持つ語だけ受け、それ以外は従来どおり「on か off で書きます」と断る

## [0.2.0] - 2026-09-29

### Changed

- **理想の線 (式・点列) を実線で描く** (破線だった)。実測は ○ で打つので線の種類で分けなくてよく、
  破線は mark・level の印だけに残る。凡例の見本も実線

## [0.1.0] - 2026-09-28

### Added

- **8 つ目のフェンス ` ```graph `** — 教科書の x-y グラフ (周波数応答・特性曲線)。
  計器の画面ではなく、値を集めて描く図。空でも枠を描き、読めなかった行は図の下の帯と Problems に出す。
- **軸** `x: 周波数 Hz log 2k..32k` / `y: 電流 mA 0..30` — 後ろから読む (範囲・log・単位・名前)。
  範囲の区切りは `..` (`2k-32k` は断る)。範囲を省くと大きさの量は 0 から、dB と deg は値を包む。
  目盛は 1-2-5 で 4〜8 本 (deg は 15・30・45・90)、対数は 10 倍ごとと 2・5。字は詰まれば間引く。
  名札は「量/単位」で、対数なら `(対数)`。
- **線** — キーの最後の語が単位 (`出力 50Ω mA:`)。値は式 (`20*log10(1/sqrt(1+(x/1.59k)^2))`) か
  1 行 1 点の点列 (`- 2k 0.38`)。式は自前の再帰下降 (`eval` 無し)、接頭辞つきの数、関数 18 個、
  200 字・32 段まで。単位の違う線は横軸を共有して縦に積んだ枠に (3 つまで)。
- **注釈** `mark` (縦線と読み値) / `level` / `band` / `text` / `peak` / `source`。
- **読み値** — `graph-fence check` と図の帯に mark と peak の表。本文の「見るべき値」と数で突き合わせる。
- **測った値** (`data: 9-1.csv`) — `.md` の隣の CSV を読み、○ で打つ (線で結ばない)。
  見出しの括弧の中が単位で、x は軸の単位に直す (kHz → Hz)。列は単位と名前で線に当たる。
  読むのは CLI と VS Code の拡張だけ (web と playground は「読めません」と言う)。
- 例 5 本 (回路 9-1 の共振曲線、AD 5-1 のボード線図、電験 6-1・3-9・12-1)、文法リファレンス (図 5 枚)、早見表。
