# 読めなかったときに何が出るか

読めなかった行は図の下の帯に、**行番号と、その行の中身と、綴りを指す印**つきで
出る。板は必ず描く (読めた所まで)。

大きさに単位が無いとき。**穴の数ではない**ので mm か cm を書く。

```copper
board: 40x20
```

斜めの線路はまだ描けない。**斜めの区間だけ断って、残りは描く。**

```copper
board: 40x20mm
copper:
  L1: line 0,10 20,10 30,5 3
```

線路の名前は端にできない (線路のどこか決まらない)。点で書く。

```copper
board: 40x20mm
copper:
  L1: line 0,10 40,10 3
parts:
  R1: resistor L1 20,15 50
```
