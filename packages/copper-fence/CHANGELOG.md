## [0.7.0] - 2026-10-04

### Added

- **部品表 (`- parts`) の見出しの下に板の行** — `基板` / `copper-clad` / `40×20mm 1.6mm εr 4.4 両面`。`ground: none` は片面

## [0.6.1] - 2026-09-30

### Fixed

- **`style:` の `on` / `off` に `constructor` などの継承された名前が通っていた** — 語を普通のオブジェクトで引いていたので、`stamp: constructor` が真として読まれ刻印が出た。自分の持つ語だけ受け、それ以外は従来どおり「on か off で書きます」と断る

## [0.6.0] - 2026-09-30

### Added

- **板の外の機器 (`type: device`) を `parts:` に書ける** — 電源・測定器 (Analog Discovery の
  W1 / CH1 / CH2)・マイク・アンテナ線を、板の外に足つきの箱で描いて島へ配線できる
  (perfboard と同じ書き方・同じ `名前.足` の綴り)。`at:` は箱の中心 (mm)、足は板のいる側の
  辺から出る (`face:` で変えられる)。配線 `- PWR.+ -- VCC red` は銅を作らず、板の縁をまたいで
  島 (線路なら足にいちばん近い点) へ届く線を銅・部品の上に描く。足は部品の足と同じくネット
  リストに `PWR.+` と出て、どこにもつながない足と、銅のない所へ引いた配線は ERC が言う。
  裏から見た図には描かない。機器の中心は板の外 60mm まで (注釈は 20mm のまま)。
  これまで板の外の物は文章でしか説明できなかった (`box` を板の外に置くと足の下に銅が無い)。

## [0.5.0] - 2026-09-30

### Added

- **足が 3〜4 本の部品を `parts:` に書ける** — `transistor[/to92|/to220] 端 端 端 [値]`
  で 2SC1815 などの TO-92 を島から島へ足で渡して置ける。端は足の並びの順に足の数だけ
  (島の名前か点)。足の名前は種類で決まり (`transistor` は `B` `C` `E`)、`check` の
  ネットリストに `Q1.B` `Q1.C` `Q1.E` と出る。丸い胴の平らな面から足が出て、足は胴から
  各端への直線、足の名前・名札・値を添える。向きは書かなければ足の総延長が最短の向き、
  `r90` `r180` `r270` `mirror` で決められる。足がどこの銅にも乗っていないときのお知らせと、
  端の数が足りないときの「端を 3 つ書きます」も 2 本足と同じ扱い。
  `mosfet` (`G` `D` `S`)、`regulator` (`IN` `GND` `OUT`。TO-92・TO-220)、
  4 本足の MMIC アンプ `mmic/sot89` (`IN` `GND` `OUT` `GND2`。SOT-89 の絵で、4 番の足はタブ。
  足の名前は本の 8-6 に揃えた) も同じ仕組み。
  `transistor` `regulator` だけを書いても姿は要らない (`to92`)。
  面実装の `transistor/sot23` は今までどおり中心の点で置く。
  なお、これまで `transistor 1,1` は「姿を書きます」と断っていたが、いまは端の数を言う。

## [0.4.0] - 2026-09-29

### Changed

- **長さはどこでも `mm` を付ける。今まで受けていた素の数を断る** (直下の CLAUDE.md の文法の
  方針 1「黙って別の意味に読まない」)。今までは線路の幅・溝・穴の径は単位を受けず、島の
  大きさは付けても付けなくてもよく、`size:` だけ必須、`h:` `cut:` は単位の概念が無かった —
  1 つのフェンスの中で揃っていなかった。書き直し:
  `line 0,10 40,10 3.06` → `3.06mm`、`gap 0.3` → `gap 0.3mm`、`pad 30,3 4x4` → `4x4mm`
  (`slot` `box` も)、`via 30,5 0.8` → `0.8mm`、`h: 1.6` → `h: 1.6mm`、`cut: 0.3` → `cut: 0.3mm`。
  エラー文が付け方 (`3mm`) を言う。地図のエディタが書く値も `mm` 付き。
  **素の数のまま受けるのは番地** (点 `20,10` と SMA の辺に沿った位置 `sma left 10` — 板の
  上の位置はいつも mm で、別の単位に読める余地が無い。`12mm,5mm` と書かせると点が読みにくく
  なるだけ) と、無次元の比誘電率 `er:`。
- **`f:` の素の数を断る** (`f: 2400000000`)。今までは Hz で読んでいた。接頭辞か `Hz` を付ける
  (`2.4G` `2.4GHz`)。
- 周波数の読み書きと等幅の帯を fence-kit の物に揃えた (vna・scope と共用)。
  描く図は 1 バイトも変わらない。`f: .5G` のように頭の 0 を省いた綴りも読む。

### Security

- 言うことに載せる行の中身で、双方向の分離の制御文字 (U+2066〜2069) も · に置き換える。
  これまでは埋め込み・上書き (U+202A〜202E) だけで、分離の字で行の見え方の並びを偽れた
  (graph-fence のセキュリティの見直しで見つかった)。

## [0.3.0] - 2026-09-28

### Changed

- **図の右下に処理系の版 (`copper-fence x.y.z`) を既定で刻む。** 今までは `style: stamp: on` を
  書いた図だけだった。刻まないときは `style:` に `stamp: off` を書く。資料に貼った図が
  どの版で描いたものかを、図を見ただけで辿れるようにするため。字は今までどおり書けない
  (処理系が埋める)。

## [0.2.0] - 2026-09-25

### Added

- **裏から見た図** — どの図の下にも、板を裏返して見た姿 (左右反転) を出す。裏の地の
  ベタ (無い板は基材)、via の穴、切り欠き、端面 SMA の腕、表の銅の透かし、裏返った目盛。
  既定で出す。`style: back: off` で消せる。マップには出さない。

## [0.1.1] - 2026-09-25

### Fixed

- **題の Ω が Windows の VS Code で別の字に化けた** (`図01 50Ω` が `50и`)。題は太字で、
  字の種類を `system-ui` だけで指していたため、日本語の UI フォントの太字で描かれていた。
  題だけ欧文のフォントを先に並べる。

## [0.1.0] - 2026-09-24

### Added

- **4 つ目のフェンス ` ```copper `** — 銅張り基板の寸法図。位置は mm の `x,y`
  (板の左上から)、板の上と左に目盛、1mm の方眼。
- **板** (`board:`) — 実寸 (`40x20mm` `4x2cm`。単位は要る)、基材の厚さ `h`、
  比誘電率 `er`、地の在りか `ground` (`back` `front` `both` `none`)、表が地の板の
  溝の幅 `cut`。書かなければ 40×20mm・1.6mm・4.4・裏ベタ。
- **銅の形** (`copper:`) — `line` (縦横の折れ線と幅、`gap` で溝)、`pad`、`via`、
  `slot`。触れ合う形は 1 つの島 (ネット)。表が地の板で島に触れない via は地の一部。
- **線路の字に幅・Z0・電気長** — マイクロストリップは Hammerstad-Jensen、CPW と
  CPWG は完全楕円積分 (算術幾何平均)。`f:` を書くと電気長 (度) と λg/4。
  図の下に板の説明と 50Ω の幅。
- **部品** (`parts:`) — 端面 SMA (`sma left 10`、`female-edge` / `male-edge`)、
  面実装 (`capacitor/1608` `diode/sod323` `ic3/sot89` など。**綴りと寸法は
  perfboard と同じ表**)、箱 (`box 中心 幅x高さ 足の数`)、足のある部品
  (端は島の名前か点)。向きは `r90` `r180` `r270` `mirror`。
- **線路の上に置いたチップは線路を切る** (切れ目は胴の長さの半分)。直角に置けば
  切らない (シャント)。
- **結合線路の隙間を測って出す** (`s0.5mm`。基材の厚さの 2 倍まで)。
- **ジャンパ** (`wires:`)、**注釈** (`notes:` — `mark` `box` `arrow` `text`、
  寸法線 `dim`、部品表 `parts`、書き出し `source`)、**見た目** (`style:` — テーマ、
  幅、方眼、刻印、ERC、お知らせ)。
- **ネットリストと ERC** — 銅に乗っていない足、SMA の中心導体が表の地に触れる、
  同じ部品の足が同じ銅、ジャンパの端が銅に乗っていない、手で切れない細さ (0.3mm)。
- **字の置き場を選ぶ** — 線路の字・部品の名札・隙間の字が、先に置いた字と部品の
  胴を避ける。
- **マップのエディタ** — 1mm の升 (既定 0.5mm 刻み)、部品と島を掴んで動かす、
  線路とジャンパの端を動かす (斜めなら横→縦に折る)、線路を引くと 50Ω の幅、
  欄 (名前・種類・値・色)、回す・裏返す・複製・消す (名前で指されていた島を消すと、
  指していた端は中心の点に書き換える)。
- CLI (`copper-fence check|render|--version`)、文法リファレンス、例 9 本。
